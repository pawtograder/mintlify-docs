# Regrade Requests

If you believe a rubric check on your graded submission was applied incorrectly — either it was marked when it shouldn't have been, or it wasn't applied when you think it should have been — you can open a **regrade request** on that specific check.

A regrade request is a back-and-forth conversation between you and the original grader on a single rubric check. The grader can adjust your score (or leave it unchanged) and respond with their reasoning. If you're not satisfied with the outcome, you can escalate the request to an instructor, whose decision is final.

<Note>
Regrade requests are only available for rubric items graded by course staff. You cannot request a regrade on self-review rubric items. See [Self-Review](/students/assignments/self-review).
</Note>

## When You Can Request a Regrade

Regrade requests are available once your submission has been graded and the grade has been released to you. Your instructor may also set a **regrade request deadline** — after that date, you can no longer open new regrade requests. While the deadline is still ahead of you, the dialog shows it before you commit: "Regrade requests must be submitted by *date*". Once it has passed, the button is replaced by a disabled **Regrade deadline passed** button and the line "The deadline was *date*".

## Opening a Regrade Request

<Steps>
<Step title="Open the graded submission">
Go to the submission. The rubric sidebar, where the regrade controls live, is shown next to every tab except **Grade**, so **Files** works and so does **Autograder Detail**. Regrade controls also appear inline on the individual comments a grader left on your files and artifacts.
</Step>
<Step title="Find the rubric check">
Locate the specific rubric check you want to dispute. A check that *was* applied has a **Request regrade for this check** button (**Request regrade** where the control is inline on a comment). A check that was *not* applied, but that you think should have been, has a **Request regrade — check not applied** button.
</Step>
<Step title="Read what happens next">
The confirmation dialog explains the workflow: you'll write a comment, the original grader will respond, you can escalate to an instructor if needed, and the instructor's decision is final. If this is a group submission, you'll also see a note that the request and any score change applies to the whole group.
</Step>
<Step title="Draft the request">
Click **Draft Regrade Request**. The request is created and you're prompted to add a comment explaining your reasoning.
</Step>
<Step title="Explain your reasoning">
Write a clear comment describing why you believe the check should be re-evaluated. Be specific — point to the relevant lines, files, or rubric criteria. Posting that first comment is what submits the request: it moves from **Draft** to **Pending** and the grader can see it.
</Step>
</Steps>

<Warning>
Only open a regrade request if you genuinely believe there was an error in grading. Frivolous or repeated bad-faith escalations may affect how future requests are handled.
</Warning>

## Request Statuses

A regrade request moves through these states:

| Status | Meaning |
|--------|---------|
| **Draft** | Created but not yet submitted to the grader |
| **Pending** | Submitted; awaiting grader review |
| **Resolved** | The grader has made a decision and (optionally) adjusted your score |
| **Escalated** | You've escalated the resolved request to an instructor |
| **Closed** | The instructor has made a final decision |

Once a request is **Closed**, it is final.

## After the Grader Responds

When the grader resolves your request, you'll be notified. Their response may:

- Adjust your score for that check (up or down)
- Leave your score unchanged with an explanation

If you're satisfied, you're done — no further action is needed.

A request can also resolve itself. If the grading comment your request pointed at is deleted while the request is still Draft or Pending, which happens when the submission is re-graded, the request is marked **Resolved** and flagged **Action needed**: "The grade this request referenced was changed during re-grading — review the updated grade and escalate if you still disagree." An **Escalated** request is left in the instructor's queue instead.

If you disagree, you can **escalate** the request to an instructor for a final decision. The **Escalate to Instructor** button appears while the request is **Resolved**, and the dialog spells out the guidelines: escalate only if you have a substantive concern, give clear reasoning, the instructor's decision is final, and frivolous escalations may affect future requests.

## Group Submissions

For group submissions:

- Any group member can open a regrade request on the submission
- The request and all comments are visible to every group member
- Any score adjustment applies to the entire group's score

## Tracking Your Requests

Your course dashboard has a **Recent Regrade Requests** section. Once you have at least one request, a **View all regrade requests →** link appears below it and opens the **My Regrade Requests** page. There is no course-menu entry for that page, so the dashboard link is the way to reach it.

Requests are grouped by submission, with a collapsible header per submission giving the assignment name, how many requests it has, and an **N actions needed** badge counting the requests whose grade changed during re-grading. Inside each group, the columns are **Status**, **Assignment**, **Submission**, **Rubric Check**, **Initial Points**, **Final Points**, **Created** and **Last Updated**.

Draft, Pending and Escalated requests sort above Resolved and Closed ones, and within each of those two blocks the newest come first. Note that **Resolved** counts as settled for sorting even though you can still escalate it, so a resolved request sorts down among the closed ones.

You can also see each request inline on the original submission, attached to the rubric check it's about. A **Regrade Requests (*N*)** panel collects every request on that submission, both in the rubric sidebar and on the submission's **Grade** tab.
