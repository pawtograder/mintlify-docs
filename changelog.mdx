This page covers changes since the end of the Spring 2026 term. Entries are grouped by month, newest first.

## September 2026

### September 10, 2026

#### Discord
- **Discord channels now have a repair path** — If a course's `#scheduling` or `#operations` channels were never created (for example, because the bot lacked permissions when the server was first connected), the **Re-invite** button on the course roster now re-creates them alongside any missing roles. Previously, dead-lettered channel creation jobs had no recovery path and the channels would stay missing for the rest of the term ([#967](https://github.com/pawtograder/platform/pull/967))
- **Fewer Discord API rate-limit errors during role sync** — The batch role sync no longer looks up each guild member twice. The redundant second lookup was exhausting Discord's per-route rate-limit bucket and producing spurious 429 errors; the sync now passes the result of its first lookup directly to the role-assignment handler ([#967](https://github.com/pawtograder/platform/pull/967))

#### GitHub
- **Forking a private handout no longer retries for hours** — When an assignment is configured to fork a private template repository but the GitHub organization does not allow forking private repos, repository creation now fails immediately with a clear message naming the remedy, instead of retrying for up to 32 hours. A generic backstop also parks any other repository whose creation job is dead-lettered, capping retries at one cycle rather than eight ([#966](https://github.com/pawtograder/platform/pull/966))
- **Handout sync now handles non-ASCII file content correctly** — Files containing accented characters, emoji, or other Unicode content are now read and written as UTF-8. Previously, the sync used a Latin-1 codec that caused patch failures and dead-lettered sync jobs for files with characters outside the ASCII range ([#970](https://github.com/pawtograder/platform/pull/970))
- **Deleted repositories no longer throttle permission sync for a whole org** — A repository that no longer exists on GitHub is now detected quickly and parked, rather than spending 93 seconds on a retry ladder and then tripping the org-wide circuit breaker. Permission sync for archived assignments is also skipped entirely ([#965](https://github.com/pawtograder/platform/pull/965))

#### Leaderboard
- **Leaderboard constraint no longer discards student grades** — A database check constraint that rejected scores above the declared maximum (which can legitimately occur with mutation-testing graders) has been removed. Leaderboard updates that fail for any reason now log a warning and continue rather than rolling back the grade that triggered them ([#964](https://github.com/pawtograder/platform/pull/964))

### September 9, 2026

#### GitHub
- **Permission sync skips redundant work on large orgs** — Repository permission sync no longer attempts to remove collaborators whose access comes from a team or org ownership, since those removals have no effect. On a course org where all access is team-based, this eliminated over a minute of wasted API calls per sync. The org member list is also skipped when there are no users to add ([#960](https://github.com/pawtograder/platform/pull/960))
- **Per-org permission sync exemptions** — Site admins can now configure a list of GitHub usernames that permission sync should never remove from repositories in a given org. This replaces a hardcoded list that applied to every org. The setting is available on the **GitHub Orgs** admin page ([#960](https://github.com/pawtograder/platform/pull/960))
- **Webhook configuration returns a clear error when the grader repo is missing** — If a solution repository was never created (for example, because an earlier step failed), the autograder configuration page now returns a 400 with an explanation rather than a generic 500 error ([#960](https://github.com/pawtograder/platform/pull/960))

### September 8, 2026

#### GitHub
- **Handout creation no longer fails for brand-new courses** — Creating a mode-2 handout repository for a course with no enrolled students no longer returns a 500. The students team is now created on demand if it does not yet exist, and the staff team grant is skipped gracefully when the staff team has not been created yet ([#959](https://github.com/pawtograder/platform/pull/959))

### September 7, 2026

#### Authentication
- **Microsoft sign-in now works on staging** — The Helm chart now sets the required OAuth redirect URI for the Azure provider. Previously, the missing redirect URI caused every Microsoft sign-in attempt to fail with a 400 error before contacting Microsoft. An optional `url` field is also available to pin sign-in to a specific Entra tenant ([#957](https://github.com/pawtograder/platform/pull/957))

#### Performance
- **Async worker drain concurrency and visibility timeout are now tunable** — The `github-async-worker` pgmq drain concurrency and visibility timeout can now be configured via Helm values (`edgeFunctions.githubAsyncWorker.drainConcurrency` and `visibilityTimeoutSeconds`). The defaults reproduce the previous hardcoded behaviour. Detailed step-level timing is now emitted for `create_repo` and `sync_repo_permissions` operations to help diagnose future latency issues ([#956](https://github.com/pawtograder/platform/pull/956))

#### Bug fixes
- **Provisioning-push retries no longer flood error alerts** — When a student push arrives while a repository is still being provisioned, the event is now reported at `info` level with its own fingerprint rather than as an `error`. Genuine readiness failures (where the repository exists but the database was never updated) continue to alert at `error` level ([#955](https://github.com/pawtograder/platform/pull/955))
- **Discord discussion stats no longer silently fail on large batches** — Author profile lookups are now fetched in bounded chunks of 50 UUIDs, preventing the URI-too-long error that caused the hourly stats update to report `0 errors` while actually failing to resolve any author names. Messages whose author could not be resolved are now counted as errors and left for the next run rather than attributed to the wrong author ([#955](https://github.com/pawtograder/platform/pull/955))

## August 2026

### August 19, 2026

#### Surveys
- **Stricter rules on survey responses** — Responses are now accepted only for published surveys that are available, not deleted, and assigned to you, and only from members of the course. Editing a submitted response is refused when the survey does not allow response editing. Late responses are still accepted, as before

### August 12, 2026

#### Bug fixes
- **Preview as student stays on its own assignment** — On the **Test Assignment** page, **Preview as student** no longer shows submissions from other assignments ([#918](https://github.com/pawtograder/platform/pull/918))
- **Discord role sync scoped to active courses** — Role synchronization now runs only for active courses and stops retrying failures that cannot succeed ([#924](https://github.com/pawtograder/platform/pull/924))
- **Long-idle tabs no longer crash** — Returning to a Pawtograder tab left open for a long time no longer errors out when you come back to it ([#902](https://github.com/pawtograder/platform/pull/902))

### August 11, 2026

#### Grading and gradebook
- **Safeguards on scores and completion** — Rubric point values are rejected if they are negative, grading completion is computed from each student's own reviews rather than an assignment-wide summary, and an out-of-date gradebook recalculation can no longer overwrite newer grades ([#922](https://github.com/pawtograder/platform/pull/922))

### August 6, 2026

#### Assignments
- **Repo-only assignments with no autograder** — An assignment can now be configured with no autograder at all. Every push to the default branch is collected as a submission for hand grading, and pushes to other branches are recorded in the commit history without becoming submissions ([#898](https://github.com/pawtograder/platform/pull/898))
- **Suggested due dates shown prominently** — When the **Suggested due dates** course flag is on, an assignment's advisory date is now surfaced clearly to students. Also fixed a timezone shift that could move dates by a day when creating an assignment ([#896](https://github.com/pawtograder/platform/pull/896))

### August 4, 2026

#### Command line
- **Pawtograder CLI published to npm** — The `pawtograder` command-line tool is now installable from npm, with the previously stubbed command groups implemented. See [CLI](/staff/cli) ([#885](https://github.com/pawtograder/platform/pull/885))

### August 3, 2026

#### Accessibility
- **Major accessibility work on student pages** — Student-facing pages were reworked for keyboard operation, focus handling, labelling, and contrast, measured against WCAG 2.1 AA, and an automated accessibility suite now runs against them on every change. This closed out the large structural barriers; a punchlist of smaller items remains open, so the student pages are not yet fully AA conformant ([#862](https://github.com/pawtograder/platform/pull/862))

#### Bug fixes
- **Preview as student on unreleased assignments** — The student preview on the **Test Assignment** page no longer closes itself when the assignment has not been released ([#887](https://github.com/pawtograder/platform/pull/887))
- **Renamed GitHub accounts re-linked** — Students and staff who rename their GitHub account are now re-matched automatically, and a course URL must be unique within its GitHub organization ([#888](https://github.com/pawtograder/platform/pull/888))

## July 2026

### July 17, 2026

#### Grading
- **Graded non-submitters flagged in the roster** — The grader roster now marks students who have been graded without ever submitting, so a stub submission created for grading is not mistaken for real work ([#865](https://github.com/pawtograder/platform/pull/865))

### July 16, 2026

#### Assignments
- **Unreleased assignments hidden from students** — Assignments that have not been released no longer appear on the student dashboard ([#866](https://github.com/pawtograder/platform/pull/866))

#### GitHub
- **Membership and repositories heal themselves** — GitHub organization membership and team assignment are reconciled the first time a student logs in, and a student repository that failed to be created is retried instead of needing staff intervention. Template repositories can also be set per deployment ([#866](https://github.com/pawtograder/platform/pull/866), [#861](https://github.com/pawtograder/platform/pull/861))

### July 6, 2026

#### Grading
- **Grade students without a submission** — Every enrolled student appears on the assignment roster. Students with no active submission show **Not submitted** and a **Grade anyway** button that creates an empty submission and opens it for grading; the progress panel counts them separately. **Bulk Assign Grading** gained an **Assign grading for all students** toggle that does the same in bulk. See [Grading assignments](/staff/assignments/grading-assignments#grade-anyway) ([#855](https://github.com/pawtograder/platform/pull/855))

#### Bug fixes
- **Non-submitter roster scoped per assignment** — Students who had submitted some other assignment in the course are no longer left off the non-submitter list for an assignment they skipped ([#859](https://github.com/pawtograder/platform/pull/859))
- **Grader names in bulk assign** — The assignee selector no longer shows blank entries while names are still loading ([#856](https://github.com/pawtograder/platform/pull/856))

## June 2026

### June 30, 2026

#### Integrations
- **LMS (LTI) Sync** — Courses can connect to Canvas or another LTI 1.3 platform to pull the roster and push assignment grades back to the LMS gradebook. Site admins register platforms, and each course maps its LTI contexts to Pawtograder sections from **Course Settings → LMS (LTI) Sync** ([#789](https://github.com/pawtograder/platform/pull/789))

### June 23, 2026

#### Grading
- **Release checks that grading is finished** — Releasing grades now verifies that the reviews it covers are complete, and judges completeness according to each reviewer's role ([#844](https://github.com/pawtograder/platform/pull/844))

#### Administration
- **Class creation requires a GitHub organization** — The admin **Create Class** form now offers a required dropdown of configured GitHub organizations and accepts a list of instructor email addresses to invite. Admins can also run team synchronization for courses they do not teach ([#846](https://github.com/pawtograder/platform/pull/846), [#834](https://github.com/pawtograder/platform/pull/834))

### June 22, 2026

#### Groups
- **Group management tidied up** — Copying groups from another assignment is now done from the assignment's group management page, and students receive write access to their group's repository however they join the group, including by invitation and by staff assignment ([#839](https://github.com/pawtograder/platform/pull/839), [#850](https://github.com/pawtograder/platform/pull/850))

#### Branding
- **Per-deployment branding** — A Pawtograder deployment can set its own product name, logo, favicon, and accent color, so an institution running its own instance sees its own branding on the login and course pages ([#840](https://github.com/pawtograder/platform/pull/840))

### June 19, 2026

#### GitHub
- **GitHub organization defaults and an in-browser file editor** — Site admins can set default template repositories per GitHub organization from the **GitHub Orgs** dashboard, admins can enter a course as an instructor, and `pawtograder.yml` and workflow files can be edited in the browser with schema validation that blocks an invalid save ([#831](https://github.com/pawtograder/platform/pull/831))

### June 18, 2026

#### Assignments
- **Per-assignment repository configuration** — Assignment setup now covers how students get and hand in code in one place: a repository per student, a fork of the student's own repository from an earlier assignment, or no repository at all with students uploading their submission files directly. Assignments can also require a pull request, with settings for the upstream base branch, how the submission pull request is identified, and whether an open pull request is itself a graded condition. Pull-request assignments add **Checks** and **Deployments** tabs to the submission view, and instructors can create a submission on a student's behalf. See [Assignment configuration](/staff/assignments/configuration) ([#781](https://github.com/pawtograder/platform/pull/781))

### June 14, 2026

#### Assignments
- **Preview a test submission as a student** — On the **Test Assignment** page, **Preview as student** shows your own test submission under student rules, so you can check what students will see before releasing ([#835](https://github.com/pawtograder/platform/pull/835))

### June 8, 2026

#### Grades
- **Correct grades on the dashboard and in rollups** — The student dashboard shows the grade for the active submission, hand-grading totals roll up correctly, and a review score is never displayed below zero ([#824](https://github.com/pawtograder/platform/pull/824), [#812](https://github.com/pawtograder/platform/pull/812))

### June 5, 2026

#### Submissions
- **New submission file viewer** — The submission **Files** view now uses the same code editor as the rest of the platform in read-only mode, with syntax highlighting and steadier handling of large files and long grading sessions ([#565](https://github.com/pawtograder/platform/pull/565), [#820](https://github.com/pawtograder/platform/pull/820))

### June 4, 2026

#### Reporting
- **Assignment dashboard and rubric report** — Each assignment has a dashboard summarizing submissions, scores, and grading progress, and instructors can build a rubric report that shows how often each rubric check was applied, filtered by section, lab, or cohort. See [Assignment dashboard](/staff/assignments/assignment-dashboard) and [Rubric report](/staff/exports#rubric-report) ([#806](https://github.com/pawtograder/platform/pull/806))

#### Bug fixes
- **Lab sections can be deleted** — Deleting a lab section now removes it instead of leaving it in place ([#811](https://github.com/pawtograder/platform/pull/811))
- **No more error page without a course role** — Opening a course you have no role in sends you back to your course list instead of showing an error ([#830](https://github.com/pawtograder/platform/pull/830))

## May 2026

### May 30, 2026

#### Assignments
- **Advisory suggested due date** — An assignment can carry an optional suggested date on or before the real due date, as guidance for students working through a multi-part assignment. It is advisory only and enforces nothing ([#791](https://github.com/pawtograder/platform/pull/791))

#### Exports
- **Assessment export and hint feedback in exports** — The CLI's `assessment export` writes a whole term of course data — assignments, rubrics, submissions, scores, tests, hints, engagement, and gradebook cells — with optional pseudonymization of who each row is about. Student feedback on autograder hints is now included in exports. See [CLI](/staff/cli) ([#746](https://github.com/pawtograder/platform/pull/746), [#780](https://github.com/pawtograder/platform/pull/780))

#### Bug fixes
- **Group repositories preserved** — Dissolving an empty group no longer removes a repository that already has submissions ([#800](https://github.com/pawtograder/platform/pull/800))

### May 29, 2026

#### Instructor tools
- **View as student** — A **View as student** button on the course home page lets an instructor pick any enrolled student and see that student's whole course, read-only. Nothing you open in this mode is recorded against the student. See [Staff overview](/staff/intro) ([#779](https://github.com/pawtograder/platform/pull/779))

### May 23, 2026

#### Grading
- **Confirm review and advance** — The rubric sidebar has a confirm button that records the review as complete and moves you to the next submission in your queue ([#695](https://github.com/pawtograder/platform/pull/695))

### May 21, 2026

#### Regrade requests
- **Course-wide regrade request management** — Instructors get a course-level regrade requests dashboard, students can request a regrade on a specific rubric check from the grade breakdown, and requests that no longer match a mark on the submission can now be found and resolved instead of sitting unnoticed ([#733](https://github.com/pawtograder/platform/pull/733), [#772](https://github.com/pawtograder/platform/pull/772))

#### Enrollment
- **Invitations no longer expire on their own** — Bulk invitations stay valid until they are accepted or withdrawn, and duplicate profiles for the same person are merged. A person invited as an instructor to two courses is now added to both ([#777](https://github.com/pawtograder/platform/pull/777), [#747](https://github.com/pawtograder/platform/pull/747))

### May 20, 2026

#### Rubrics
- **Rubric editor with a visual tree** — The rubric editor gained a drag-and-drop outline of parts, criteria, and checks alongside the YAML view, and YAML rubrics can reuse shared definitions by reference. Copying and pasting rubric YAML saves correctly, and a preview no longer drops checks that share an identifier ([#766](https://github.com/pawtograder/platform/pull/766), [#775](https://github.com/pawtograder/platform/pull/775), [#773](https://github.com/pawtograder/platform/pull/773))

### May 19, 2026

#### Instructor tools
- **Commit history, on-demand grading, and GitHub diagnostics** — Instructors can open a student repository's commit list, start a grading run on any commit from it, and use a diagnostics page that reports the state of a course's GitHub organization, repositories, and permissions ([#764](https://github.com/pawtograder/platform/pull/764), [#750](https://github.com/pawtograder/platform/pull/750))
- **Faster instructor pages** — Large instructor tables stream in and render only the rows in view, so pages with thousands of rows stay responsive. Batch group updates and large assignment deletions were also moved off the request path ([#708](https://github.com/pawtograder/platform/pull/708), [#765](https://github.com/pawtograder/platform/pull/765))

#### Bug fixes
- **Handout sync, gradebook refresh, and live updates** — Handouts sync files over 5 MB and propagate deletions to the repositories they sync to, gradebook cells recalculate when a student's active submission changes, the submission history panel updates as reviews change, and the code viewer follows the Pawtograder theme rather than your operating system's ([#749](https://github.com/pawtograder/platform/pull/749), [#783](https://github.com/pawtograder/platform/pull/783), [#763](https://github.com/pawtograder/platform/pull/763), [#769](https://github.com/pawtograder/platform/pull/769), [#770](https://github.com/pawtograder/platform/pull/770))

### May 18, 2026

#### Discussion
- **Mark a thread as duplicate** — Staff can mark a discussion thread as a duplicate of another, pointing readers at the answered thread ([#727](https://github.com/pawtograder/platform/pull/727))

### May 17, 2026

#### Accessibility
- **Accessibility and usability pass** — A broad round of fixes to labelling, focus handling, contrast, and keyboard operation across the platform, plus a **Keyboard shortcuts** entry in the support menu that lists the shortcuts available on the page you are on ([#753](https://github.com/pawtograder/platform/pull/753), [#744](https://github.com/pawtograder/platform/pull/744))

### May 16, 2026

#### Security
- **Hardened chat attachments and page content policy** — Attachments in office-hours help request chats are sanitized before display, and the platform now sends a strict content security policy ([#752](https://github.com/pawtograder/platform/pull/752))

### May 15, 2026

#### Assignments
- **Automatic late tokens** — A course can let students push after the deadline and have a late token spent for them. Where it is enabled, the assignment page says so, and submitting late applies a token if the student has one left. See [Late tokens and extensions](/students/assignments/late-tokens-and-extensions) ([#692](https://github.com/pawtograder/platform/pull/692))

### April 28, 2026

Column and section filter dropdowns gained **Select all** and **Select none** buttons. See [Gradebook](/staff/gradebook) ([#735](https://github.com/pawtograder/platform/pull/735))

#### Autograding
- **Clear error when no files match** — If no repository files match an assignment's configured submission file patterns, the submission is rejected with a message naming the patterns that matched nothing, instead of grading an empty submission ([#739](https://github.com/pawtograder/platform/pull/739))

#### Performance
- **Faster discussion and submission pages** — Long discussion threads and submission pages load noticeably faster ([#740](https://github.com/pawtograder/platform/pull/740))

### April 23, 2026

#### Grading
- **Bulk release and unrelease** — The instructor submissions table supports row selection with checkboxes and an **All in view** option, so **Release** and **Unrelease** act on exactly the rows you picked ([#730](https://github.com/pawtograder/platform/pull/730))
- **Group mentor column** — The instructor submissions table shows a **Group mentor** column, with a multi-select filter, when the assignment's groups have mentors ([#731](https://github.com/pawtograder/platform/pull/731))
- **Clear message when feedback is released** — A grader who tries to change marks on a released review now sees an explanation and is directed to ask an instructor to unrelease it ([#724](https://github.com/pawtograder/platform/pull/724))

#### Bug fixes
- **Individual scores on group assignments** — Student views show the individual score on group assignments, and the gradebook updates when those grades change after release ([#729](https://github.com/pawtograder/platform/pull/729), [#725](https://github.com/pawtograder/platform/pull/725))
