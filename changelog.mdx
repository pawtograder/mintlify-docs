## July 2026

### July 23, 2026

#### Infrastructure
- **Vault secrets seeded on deploy** — Cache-invalidation vault secrets are now automatically seeded during every deployment, including preview deployments, eliminating a manual step when standing up new environments ([#873](https://github.com/pawtograder/platform/pull/873))

### July 17, 2026

#### Grading improvements
- **Placeholder column in assignment roster** — The assignment roster now includes a hidden-by-default **Placeholder** column. Rows with an instructor-created stub submission (from **Grade anyway** or a no-submission auto-stub) show a **Yes** badge so graders can distinguish them from real zero-score submissions. The column supports show/hide and Yes/No filtering ([#865](https://github.com/pawtograder/platform/pull/865))

#### Bug fixes
- **Unreleased assignments hidden from student dashboard** — Students no longer see assignments whose release date is in the future on their Assignments tab. Previously, the student dashboard RPC bypassed row-level security and returned all non-archived assignments regardless of release date ([#866](https://github.com/pawtograder/platform/pull/866))
- **GitHub org membership reconciled on first login** — Students who were already members of the course GitHub org (added out-of-band or via a previous class) were stuck on the "accept your invitation" banner forever. The auth callback now reconciles GitHub org membership in the background on first GitHub login, clearing the banner automatically ([#866](https://github.com/pawtograder/platform/pull/866))
- **Self-healing student repository creation** — If a student's GitHub repository was created blank (due to a template mirroring race), Pawtograder now detects the empty repo and automatically deletes and regenerates it. Deterministic failures (empty or missing template) are recorded on the repository row with a human-readable error and a **Retry creation** button, rather than retrying forever. A background reconciler re-enqueues transient stuck repos every 15 minutes ([#861](https://github.com/pawtograder/platform/pull/861))

### July 7, 2026

#### Grading improvements
- **Grade students without a submission** — Every enrolled student now appears on the assignment roster, even without an active submission. Instructors and graders can click **Grade anyway** on any non-submitter row to create an empty stub submission and navigate directly to the grading page. If the student later submits, the stub is automatically superseded. The grading progress panel shows a separate **Not submitted: N** count so non-submitters don't skew completion percentages ([#855](https://github.com/pawtograder/platform/pull/855))
- **Bulk assign grading for all students** — The **Bulk Assign Grading** form now includes an **Assign grading for all students** toggle. When enabled, empty stub submissions are created for non-submitters (respecting section, lab, and tag filters) before grading assignments are drafted, ensuring every enrolled student can be assigned a grader regardless of submission status ([#855](https://github.com/pawtograder/platform/pull/855))

#### Bug fixes
- **Fixed non-submitter roster scoping** — Corrected a bug where students who had submitted any other assignment in the course were incorrectly excluded from the non-submitter list for assignments they hadn't submitted to, causing the **Grade anyway** button to not appear for them ([#859](https://github.com/pawtograder/platform/pull/859))
- **Fixed bulk assign assignee display** — Grader names in the bulk assign selector now fall back to the profile ID when a name is not yet loaded, preventing blank or broken entries in the assignee list ([#856](https://github.com/pawtograder/platform/pull/856))
