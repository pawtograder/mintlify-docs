## August 2026

### August 3, 2026

#### Accessibility improvements
- **WCAG 2.1 AA compliance for student-facing pages** — Student-facing routes now meet WCAG 2.1 AA accessibility standards. Improvements include proper semantic heading hierarchy on submission results and gradebook pages, keyboard-operable navigation menus and gradebook group toggles, visible focus indicators throughout, responsive reflow at 320px/400% zoom for discussion and office hours layouts, and screen-reader live regions for realtime connection status and autograder error alerts. The What-If gradebook editor is now fully keyboard-operable with focus return on close ([#862](https://github.com/pawtograder/platform/pull/862))

#### Bug fixes
- **Fixed Test Assignment preview for unreleased assignments** — Instructors previewing their own test submission on an assignment that has not yet been released were incorrectly redirected to the all-courses dashboard. The preview now stays on the submission page. When an instructor is masquerading as an enrolled student and hits an unreleased assignment, they are now redirected to the course page (where the view-as banner and exit button remain visible) rather than the dashboard ([#887](https://github.com/pawtograder/platform/pull/887))
- **Enforced unique class slug per GitHub org** — Two classes sharing the same GitHub template prefix in the same organization would fight over the same GitHub teams, causing students to be evicted from teams and org-confirmation to fail. A unique constraint now prevents this, with a clear error message naming the conflicting class ([#888](https://github.com/pawtograder/platform/pull/888))
- **Automatic GitHub org reconciliation on login** — Users who were already a member of a course's GitHub organization (joined via another class or added out-of-band) were stuck on the "accept your invitation" banner indefinitely. Pawtograder now automatically reconciles GitHub org membership in the background when a user with a linked GitHub account logs in and has an unconfirmed enrollment ([#866](https://github.com/pawtograder/platform/pull/866))
- **Renamed GitHub logins no longer break team sync** — If a student renamed their GitHub account, the team sync worker would fail and trip the shared circuit breaker, slowing invitations for all other students in the org. Pawtograder now re-resolves the current login from the stored GitHub account ID and retries the invitation automatically ([#888](https://github.com/pawtograder/platform/pull/888))
- **Unreleased assignments hidden from student dashboard** — Assignments whose release date is in the future no longer appear on the student Assignments tab. Previously, the student dashboard RPC returned all non-archived assignments regardless of release date ([#866](https://github.com/pawtograder/platform/pull/866))

## July 2026

### July 7, 2026

#### Grading improvements
- **Grade students without a submission** — Every enrolled student now appears on the assignment roster, even without an active submission. Instructors and graders can click **Grade anyway** on any non-submitter row to create an empty stub submission and navigate directly to the grading page. If the student later submits, the stub is automatically superseded. The grading progress panel shows a separate **Not submitted: N** count so non-submitters don't skew completion percentages ([#855](https://github.com/pawtograder/platform/pull/855))
- **Bulk assign grading for all students** — The **Bulk Assign Grading** form now includes an **Assign grading for all students** toggle. When enabled, empty stub submissions are created for non-submitters (respecting section, lab, and tag filters) before grading assignments are drafted, ensuring every enrolled student can be assigned a grader regardless of submission status ([#855](https://github.com/pawtograder/platform/pull/855))

#### Bug fixes
- **Fixed non-submitter roster scoping** — Corrected a bug where students who had submitted any other assignment in the course were incorrectly excluded from the non-submitter list for assignments they hadn't submitted to, causing the **Grade anyway** button to not appear for them ([#859](https://github.com/pawtograder/platform/pull/859))
- **Fixed bulk assign assignee display** — Grader names in the bulk assign selector now fall back to the profile ID when a name is not yet loaded, preventing blank or broken entries in the assignee list ([#856](https://github.com/pawtograder/platform/pull/856))
