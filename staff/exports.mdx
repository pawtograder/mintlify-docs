# Exporting Course Data

Pawtograder exposes several CSV exports for course staff. Each is reached
by an **Export to CSV** button on the corresponding management page.
Exports apply current filters where applicable, are UTF-8 encoded (with
BOM where the file is meant to be opened in Excel), and use formula-safe
quoting.

## Enrollment Roster

**Where**: Manage course → Enrollments → **Export to CSV**.

Exports every row currently visible in the enrollments table (the export
honors active filters). Columns:

| Column | Notes |
|---|---|
| Status | `Enrolled`, `Dropped`, or the invitation status. |
| Name | Profile name, or invitation name. |
| Email | Account email, or invitation email. |
| Role | `student`, `grader`, `instructor`. |
| Class Section | Section name, or `Not assigned`. |
| Lab Section | Lab section name, or `Not assigned`. |
| GitHub Username | Empty for pending invitations. |
| GitHub Org Status | `Joined` / `Not joined`. |
| SIS User ID | SIS identifier if linked. |
| SIS Linked | `Yes` / `No`. |
| SIS Sync Opt Out | `Yes` / `No`. |
| Tags | Semicolon-separated tag names, or `No tags`. |

Filename: `enrollments-<course_id>-<YYYY-MM-DD>.csv`.

## Lab Roster

**Where**: Manage course → Lab Roster → select a lab section → **Export to CSV**.

Exports the students assigned to the selected lab section, plus columns
for each lab assignment configured on the course (attendance / completion
per lab). Base columns:

- Lab Section
- Name
- Email
- GitHub Username

Filename: `lab-roster-<section>-<YYYY-MM-DD>.csv`.

## Assignment Groups

**Where**: Manage course → Assignments → *assignment* → Groups → **Export as CSV**.

Exports group composition for a single assignment. Rows are sorted by
group name; students who are not in any group are emitted with the group
name `(Ungrouped)`.

| Column | Format |
|---|---|
| GroupName | Group name, or `(Ungrouped)`. |
| StudentNames | Comma-separated list of `Name <email>` per member, sorted. |
| MentorName | Assigned mentor/grader as `Name <email>`, or empty if none. |

Filename: `assignment_groups_<YYYY-MM-DD>.csv`.

## Gradebook

**Where**: Manage course → Gradebook → **Export**.

Exports the full gradebook (all students, all columns). A toggle in the
export dialog controls whether render expressions (formulas) are
exported alongside their computed values. The file is UTF-8 with BOM so
Excel opens it correctly.

Filename: `gradebook.csv`.

## Survey Responses

**Where**: Manage course → Surveys → *survey* → Responses → **Export**.

Exports the responses to a single survey. Columns are one per survey
question plus identification columns. UTF-8 with BOM.

Filename: `<survey_title>_responses_<timestamp>.csv`.

## Discussion Engagement

**Where**: Manage course → Discussion Engagement → **Export CSV**.

Exports the per-student engagement metrics shown on the page (posts,
replies, watches, etc.) for the current course.

Filename: `discussion-engagement-<course_id>-<YYYY-MM-DD>.csv`.

## Assessment Export (CLI)

The Pawtograder CLI provides a privacy-controlled bulk export of rubrics,
scores, autograder test results, Feedbot hint feedback, and gradebook
columns for a class. Run with:

```bash
npx pawtograder assessment export --class <id-or-slug> [options]
```

### Output files (per assignment)

| File | Contents |
|---|---|
| `manifest.json` | Export metadata, identity mode, totals |
| `rubric.json` | Rubric hierarchy (parts, criteria, checks) |
| `autograder.json` | Autograder configuration and test definitions |
| `submissions.json` | Active (or all) submissions with subject/group tokens |
| `scores.json` | Rubric check scores from the final grading review |
| `tests.json` | Autograder test results per submission |
| `hints.json` | Feedbot hint feedback — both student ratings (`source: feedback`) and cached LLM responses (`source: llm`) |
| `error-pin-engagement.json` | Per-student read/like engagement with discussion posts pinned to autograder errors |
| `instructor-build-output.json` | Hidden grader build logs (only with `--with-instructor-build-output`) |

### Identity modes

| Mode | Description |
|---|---|
| `opaque` (default) | Random per-run salt + server pepper; tokens are stable within one run but not reproducible across runs |
| `hash` | Deterministic from `--salt` + server pepper; joinable across runs on the same deployment |
| `raw` | Real ids/emails/names; requires `--i-understand-pii` |

### Key options

| Option | Description |
|---|---|
| `--assignment <slug>` | Export only specific assignments (repeatable) |
| `--skip-gradebook` | Omit gradebook column metadata |
| `--all-submissions` | Include every submission attempt, not just the active one |
| `--with-test-output` | Include autograder test output text (truncated to `--test-output-max-bytes`) |
| `--with-instructor-build-output` | Include hidden grader build logs (path-sanitized) |
| `--instructor-build-output-from-sentinel <text>` | Trim each build log to start at this substring |
| `--concurrency <n>` | Parallel assignment exports (1–8, default 4) |

### Hint feedback format

`hints.json` contains two types of rows:

- **`source: feedback`** — a student explicitly rated a hint (useful/not useful) and optionally left a comment. Fields: `submission`, `grader_test`, `rater`, `useful`, `comment`.
- **`source: llm`** — a cached Feedbot LLM response for a test the student saw, where no explicit rating exists. Fields: `submission`, `grader_test`, `subject`, `hint`.

When a student rated a hint, only the `feedback` row is emitted (the `llm` row is deduplicated).

### Error-pin engagement format

`error-pin-engagement.json` has one row per submission × pinned discussion post × student participant. Fields: `submission`, `subject`, `discussion_thread_id`, `error_pin_id`, `grader_test`, `read_at`, `liked`.

## Submissions Export (CLI)

Export submission source files with the same identity modes as the assessment export:

```bash
npx pawtograder submissions export --class <id-or-slug> [options]
```

Outputs `submissions.json` (or `.csv`) and `files.json` (or `.csv`) per assignment. Key options:

| Option | Description |
|---|---|
| `--format json\|csv` | JSON includes file contents; CSV is a metadata index only |
| `--all-submissions` | Include every attempt, not just the active one |
| `--with-binary` | Include binary file contents as base64 |
| `--include-file <glob>` | Only export files matching this glob (repeatable) |
| `--exclude-file <glob>` | Skip files matching this glob (repeatable) |
