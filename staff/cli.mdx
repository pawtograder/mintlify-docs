# Command Line Interface

The Pawtograder CLI is a command-line tool for instructors and site administrators to automate course management tasks. It provides programmatic access to Pawtograder's core functionality, enabling bulk operations, scripting, and integration with other tools.

## Installation

Run without installing:

```bash
npx @pawtograder/cli --help
```

Or install globally to get the `pawtograder` command:

```bash
npm install -g @pawtograder/cli
pawtograder --help
```

Requires Node.js 20 or later.

<Note>
You can also run the CLI from a checkout of the platform repository using `npm run cli -- <command>`. This is useful for development or if you need a version not yet published to npm.
</Note>

## Authentication

Before using the CLI, you must authenticate with an API token.

### Creating an API Token

1. Log in to Pawtograder
2. Navigate to **Settings → API Tokens**
3. Click **Create New Token**
4. Give your token a descriptive name and select the appropriate scopes (`cli:read` for read commands, `cli:write` for commands that change data)
5. Copy the generated token (you won't be able to see it again)

### Logging In

```bash
# Interactive login (prompts for token — keeps it out of shell history)
pawtograder login

# Login with token directly (for scripts and CI)
pawtograder login --token YOUR_TOKEN_HERE
```

Credentials are stored in `~/.pawtograder/credentials.json`.

For self-hosted deployments, point `--url` at your deployment's **API gateway origin** (not the web host):

```bash
pawtograder login --url https://api.your-school.edu
```

### Managing Authentication

```bash
# Check current user
pawtograder whoami

# Log out
pawtograder logout
```

## Available Commands

### Reading data

| Command | Purpose |
|---|---|
| `classes list` / `classes show <id>` | Classes your token can see |
| `assignments list` / `assignments show <id>` | Assignments in a class |
| `submissions list -c <class> -a <assignment>` | Roster with active submission and scores |
| `reviews list -c <class> -a <assignment>` | Review assignments and completion state |
| `discussions list -c <class>` | Discussion topics with thread and question counts |
| `help-requests list -c <class>` | Office-hours help queue |
| `rubrics list` / `rubrics export` | Rubrics, and YAML export |
| `flashcards list` | Flashcard decks |
| `repos list -c <class> -a <assignment>` | Student repositories for an assignment |

Every `list` command accepts `--json` for machine-readable output:

```bash
pawtograder submissions list -c cs3500-fall-2026 -a hw-1 --json | jq '.submissions[] | select(.total_score == null)'
```

### Changing data

| Command | Purpose |
|---|---|
| `assignments copy` / `assignments delete` | Copy an assignment between classes; delete one |
| `reviews assign` | Create review assignments across graders |
| `help-requests close --id <id>` | Close or resolve a help request (instructors only) |
| `rubrics import` | Import a rubric from YAML |
| `flashcards copy` / `surveys copy` | Copy decks or surveys between classes |
| `submissions comments import` / `sync` | Batch comment ingestion |
| `submissions artifacts import` | Import artifact blobs from a manifest |

Commands that write accept `--dry-run` where a preview is meaningful.

### Assignments

```bash
# List assignments for a class
pawtograder assignments list --class <identifier>

# Copy assignments between classes
pawtograder assignments copy \
  --source-class <slug> \
  --target-class <slug> \
  --all

# Copy with schedule (CSV file with dates)
pawtograder assignments copy \
  --source-class <slug> \
  --target-class <slug> \
  --schedule <file.csv>

# Delete an assignment
pawtograder assignments delete <identifier> \
  --class <identifier> \
  --force
```

#### Assignment copy options

- `--assignment <slug>`: Copy a single assignment
- `--all`: Copy all assignments from source class
- `--schedule <file>`: Copy assignments with date overrides from CSV
- `--dry-run`: Preview changes without making them
- `--skip-repos`: Skip repository operations
- `--skip-rubrics`: Skip rubric copying
- `--skip-surveys`: Skip survey copying
- `--workdir <path>`: Local directory for git clones (required for repo operations)
- `--concurrency <n>`: Parallel operations (1-8, default 4)
- `--delay-ms <ms>`: Delay between clone batches in milliseconds

### Reviews

`reviews assign` distributes submissions across active graders and instructors, balancing on how much each already holds. It honors grading conflicts and never assigns someone their own submission.

```bash
# Preview a balanced split
pawtograder reviews assign -c cs3500-fall-2026 -a hw-1 --due-date 2026-09-15 --dry-run

# One assignment per rubric part
pawtograder reviews assign -c cs3500-fall-2026 -a hw-1 --due-date 2026-09-15 --by-part

# Restrict the grader pool
pawtograder reviews assign -c cs3500-fall-2026 -a hw-1 --due-date 2026-09-15 \
  --grader <profile-id> --grader <profile-id>

# Supply an explicit manifest
pawtograder reviews assign -c cs3500-fall-2026 -a hw-1 --due-date 2026-09-15 \
  --file drafts.json
```

A bare `--due-date` (e.g. `2026-09-15`) means end of that day in the class's time zone. Append a time (`2026-09-15T17:00`) for a specific time, or pass a timestamp with an offset to be explicit.

Re-running is safe: existing assignments are reused rather than duplicated.

### Rubrics

```bash
# List rubrics for an assignment
pawtograder rubrics list --assignment <identifier> --class <identifier>

# Export rubric to YAML
pawtograder rubrics export \
  --assignment <identifier> \
  --class <identifier> \
  --type grading \
  --output rubric.yml

# Preview what an import would change (validates against the live rubric)
pawtograder rubrics import \
  --assignment <identifier> \
  --class <identifier> \
  --file rubric.yml \
  --type grading \
  --dry-run

# Apply the import
pawtograder rubrics import \
  --assignment <identifier> \
  --class <identifier> \
  --file rubric.yml \
  --type grading
```

Rubric types: `grading`, `self_review`, `meta`

### Submissions

```bash
# List submissions with scores
pawtograder submissions list -c <class> -a <assignment>

# Import submission comments
pawtograder submissions comments import \
  --class <identifier> \
  --assignment <identifier> \
  --file batch-results.json \
  --author-profile-id <uuid>

# Import artifacts
pawtograder submissions artifacts import \
  --class <identifier> \
  --assignment <identifier> \
  --file manifest.json \
  --overwrite
```

### Help requests

```bash
# List the office-hours queue
pawtograder help-requests list -c <class> --status active

# Close a request
pawtograder help-requests close --id <id> --status resolved \
  --resolution-status staff_helped
```

### Surveys and flashcards

```bash
# Copy all surveys to a new class
pawtograder surveys copy --source-class <slug> --target-class <slug> --all

# Copy flashcard decks
pawtograder flashcards copy --source-class <slug> --target-class <slug> --all
```

## Repository maintenance

`repos sync-grade-workflow` and `repos copy-after-source-due` run **git on your machine over SSH**, not on the server, so they need a writable `--workdir` and working GitHub SSH access.

### Sync grade workflow

Sync `.github/workflows/grade.yml` from handout to all student repos:

```bash
pawtograder repos sync-grade-workflow \
  --class <identifier> \
  --assignment <identifier> \
  --workdir <path> \
  --dry-run
```

### Cross-assignment copy

Copy files from source assignment repos to target assignment repos after source due date:

```bash
pawtograder repos copy-after-source-due \
  --class <identifier> \
  --source-assignment <identifier> \
  --target-assignment <identifier> \
  --workdir <path>
```

## Environment variables

| Variable | Effect |
|---|---|
| `PAWTOGRADER_HTTP_TIMEOUT_MS` | Abort requests after this many milliseconds. Unset means no timeout. |
| `PAWTOGRADER_VERBOSE=1` | Log each request and its timing to stderr. |
| `DEBUG=1` | Same as above, plus stack traces on unexpected errors. |

The CLI does not read `.env` files when installed from npm.

## Common workflows

### Copy course to new semester

```bash
# 1. Copy all assignments with repositories
pawtograder assignments copy \
  --source-class cs3500-fall-2025 \
  --target-class cs3500-spring-2026 \
  --all \
  --workdir ~/pawtograder-repos

# 2. Copy surveys
pawtograder surveys copy \
  --source-class cs3500-fall-2025 \
  --target-class cs3500-spring-2026 \
  --all

# 3. Copy flashcard decks
pawtograder flashcards copy \
  --source-class cs3500-fall-2025 \
  --target-class cs3500-spring-2026 \
  --all
```

### Assign grading work

```bash
# Preview a balanced split, then apply
pawtograder reviews assign -c cs3500-spring-2026 -a hw-1 \
  --due-date 2026-09-15 --dry-run

pawtograder reviews assign -c cs3500-spring-2026 -a hw-1 \
  --due-date 2026-09-15
```

### Export and modify rubrics

```bash
# Export rubric
pawtograder rubrics export \
  --assignment hw1 --class cs3500 --type grading --output hw1-rubric.yml

# Edit hw1-rubric.yml locally, then preview the diff
pawtograder rubrics import \
  --assignment hw1 --class cs3500 --file hw1-rubric.yml --type grading --dry-run

# Apply
pawtograder rubrics import \
  --assignment hw1 --class cs3500 --file hw1-rubric.yml --type grading
```

## Troubleshooting

### Authentication issues

If you encounter authentication errors:

1. Verify your token is valid: `pawtograder whoami`
2. Check token scopes match the required permissions (`cli:read` / `cli:write`)
3. For self-hosted deployments, ensure `--url` points at the API gateway origin, not the web host. If the CLI reports "API returned an HTML page", you are pointing at the wrong URL.

### Repository operations

If git operations fail:

1. Ensure you have SSH access to GitHub
2. Verify the workdir has sufficient disk space
3. Check network connectivity
4. Try reducing `--concurrency` for rate-limited operations

### Performance

For large operations:

- Use `--concurrency` to control parallel operations
- Add `--delay-ms` to avoid rate limiting
- Consider running operations during off-peak hours
