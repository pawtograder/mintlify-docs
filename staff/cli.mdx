# Command Line Interface

The Pawtograder CLI is a command-line tool for instructors and site administrators to automate course management tasks. It provides programmatic access to Pawtograder's core functionality, enabling bulk operations, scripting, and integration with other tools.

## Installation

Install the CLI from npm — no checkout required:

```bash
npm install -g @pawtograder/cli
pawtograder --help
```

Or run it without installing:

```bash
npx @pawtograder/cli --help
```

Requires Node.js 20 or later.

You can also run it from a clone of the platform repository:

```bash
npm run cli -- <command> [options]
```

## Authentication

Before using the CLI, authenticate with an API token.

### Creating an API token

1. Log in to Pawtograder.
2. Navigate to **Settings → API Tokens**.
3. Create a new token with `cli:read` for read commands, or `cli:write` for commands that change data.
4. Copy the token — it starts with `mcp_`.

### Logging in

```bash
pawtograder login
```

You are prompted for the token. It is stored in `~/.pawtograder/credentials.json`.

You can also provide the token directly:

```bash
pawtograder login --token mcp_your_token_here
```

For self-hosted deployments, point `--url` at your deployment's **API gateway origin** (not the web host):

```bash
pawtograder login --url https://api.your-school.edu
```

### Managing authentication

```bash
# Check current user
pawtograder whoami

# Log out
pawtograder logout
```

## Available commands

### Classes

```bash
# List all classes your token can see
pawtograder classes list

# Show details for a specific class
pawtograder classes show <id>
```

### Assignments

```bash
# List assignments for a class
pawtograder assignments list --class <identifier>

# Show assignment details
pawtograder assignments show <identifier> --class <identifier>

# Copy assignments between classes
pawtograder assignments copy \
  --source-class <slug> \
  --target-class <slug> \
  --all

# Copy with schedule (CSV file with dates)
pawtograder assignments copy \
  --source-class <slug> \
  --target-class <slug> \
  --schedule <file.csv>

# Delete an assignment
pawtograder assignments delete <identifier> \
  --class <identifier> \
  --force
```

#### Assignment copy options

| Option | Description |
|--------|-------------|
| `--assignment <slug>` | Copy a single assignment |
| `--all` | Copy all assignments from source class |
| `--schedule <file>` | Copy assignments with date overrides from CSV |
| `--dry-run` | Preview changes without making them |
| `--skip-repos` | Skip repository operations |
| `--skip-rubrics` | Skip rubric copying |
| `--skip-surveys` | Skip survey copying |
| `--workdir <path>` | Local directory for git clones (required for repo operations) |
| `--concurrency <n>` | Parallel operations (1-8, default 4) |
| `--delay-ms <ms>` | Delay between clone batches in milliseconds |

### Submissions

```bash
# List submissions for an assignment (roster with scores)
pawtograder submissions list \
  --class cs3500-fall-2025 \
  --assignment hw1

# Include students who have not submitted
pawtograder submissions list \
  --class cs3500-fall-2025 \
  --assignment hw1 \
  --include-non-submitters

# Import submission comments
pawtograder submissions comments import \
  --class <identifier> \
  --assignment <identifier> \
  --file batch-results.json \
  --author-profile-id <uuid>

# Sync comments (insert + soft-delete missing)
pawtograder submissions comments sync \
  --class <identifier> \
  --assignment <identifier> \
  --file batch-results.json \
  --rubric-part-id <id>

# Import artifacts
pawtograder submissions artifacts import \
  --class <identifier> \
  --assignment <identifier> \
  --file manifest.json \
  --overwrite
```

### Reviews

```bash
# List review assignments
pawtograder reviews list \
  --class cs3500-fall-2025 \
  --assignment hw1

# Assign grading work (balanced round-robin)
pawtograder reviews assign \
  --class cs3500-fall-2025 \
  --assignment hw1 \
  --due-date 2026-09-15

# Preview without writing
pawtograder reviews assign \
  --class cs3500-fall-2025 \
  --assignment hw1 \
  --due-date 2026-09-15 \
  --dry-run

# Assign per rubric part
pawtograder reviews assign \
  --class cs3500-fall-2025 \
  --assignment hw1 \
  --due-date 2026-09-15 \
  --by-part

# Assign from an explicit manifest
pawtograder reviews assign \
  --class cs3500-fall-2025 \
  --assignment hw1 \
  --due-date 2026-09-15 \
  --file drafts.json
```

`reviews assign` balances submissions across active graders and instructors,
honoring `grading_conflicts` and never assigning someone their own submission.
A bare `--due-date` (e.g. `2026-09-15`) means end of that day in the class's
time zone. Append `T17:00` for a specific time, or pass a timestamp with an
offset to be explicit.

Re-running is safe: existing assignments are reused rather than duplicated.

### Help requests

```bash
# List office-hours help requests
pawtograder help-requests list --class cs3500-fall-2025

# Filter by status ('active' means open or in_progress)
pawtograder help-requests list \
  --class cs3500-fall-2025 \
  --status active

# Close a help request
pawtograder help-requests close --id <id>

# Close with resolution details
pawtograder help-requests close \
  --id <id> \
  --status resolved \
  --resolution-status staff_helped \
  --notes "Helped student debug null pointer"
```

### Discussions

```bash
# List discussion topics with thread and question counts
pawtograder discussions list --class cs3500-fall-2025
```

### Rubrics

```bash
# List rubrics for an assignment
pawtograder rubrics list \
  --assignment <identifier> \
  --class <identifier>

# Export rubric to YAML
pawtograder rubrics export \
  --assignment <identifier> \
  --class <identifier> \
  --type grading \
  --output rubric.yml

# Preview import without making changes
pawtograder rubrics import \
  --assignment <identifier> \
  --class <identifier> \
  --file rubric.yml \
  --type grading \
  --dry-run

# Import rubric from YAML
pawtograder rubrics import \
  --assignment <identifier> \
  --class <identifier> \
  --file rubric.yml \
  --type grading
```

Rubric types: `grading`, `self_review`, `meta`

## Repository maintenance

Repository commands use local SSH git operations and require a writable `--workdir`.

<Warning>
Repository commands require SSH access to GitHub. Ensure your SSH keys are configured and you have access to the course organization.
</Warning>

### List repositories

```bash
pawtograder repos list \
  --class <identifier> \
  --assignment <identifier>
```

### Sync grade workflow

Sync `.github/workflows/grade.yml` from handout to all student repos:

```bash
pawtograder repos sync-grade-workflow \
  --class <identifier> \
  --assignment <identifier> \
  --workdir <path>
```

<Note>
This command is only available for assignments with the autograder enabled. For repo-only (no-autograder) assignments, use the autograder toggle on the assignment's Autograder page instead.
</Note>

Options:
- `--dry-run`: Preview changes only
- `--concurrency <n>`: Parallel operations (1-8, default 2)
- `--delay-ms <ms>`: Delay between batches

### Cross-assignment copy

Copy files from source assignment repos to target assignment repos after source due date:

```bash
pawtograder repos copy-after-source-due \
  --class <identifier> \
  --source-assignment <identifier> \
  --target-assignment <identifier> \
  --workdir <path>
```

Options:
- `--dry-run`: Preview with rsync -n only
- `--mirror-delete`: Pass rsync --delete (excludes .git)
- `--concurrency <n>`: Parallel operations (1-8, default 2)

## JSON output

Every `list` command accepts `--json` to emit the raw API response instead of a formatted table, so output can be piped into `jq`:

```bash
pawtograder submissions list -c cs3500-fall-2025 -a hw1 --json \
  | jq '.submissions[] | select(.total_score == null)'
```

## Environment variables

| Variable | Effect |
|----------|--------|
| `PAWTOGRADER_HTTP_TIMEOUT_MS` | Abort requests after this many milliseconds. Unset means no timeout. Raise it for large artifact imports. |
| `PAWTOGRADER_VERBOSE=1` | Log each request and its timing to stderr. |
| `DEBUG=1` | Same as above, plus stack traces on unexpected errors. |

## Common workflows

### Copy course to new semester

```bash
# 1. Copy all assignments with repositories
pawtograder assignments copy \
  --source-class cs3500-fall-2025 \
  --target-class cs3500-spring-2026 \
  --all \
  --workdir ~/pawtograder-repos

# 2. Copy surveys
pawtograder surveys copy \
  --source-class cs3500-fall-2025 \
  --target-class cs3500-spring-2026 \
  --all

# 3. Copy flashcard decks
pawtograder flashcards copy \
  --source-class cs3500-fall-2025 \
  --target-class cs3500-spring-2026 \
  --all
```

### Assign grading work

```bash
# Preview a balanced split, one assignment per submission
pawtograder reviews assign \
  -c cs3500-fall-2026 \
  -a hw-1 \
  --due-date 2026-09-15 \
  --dry-run

# Apply
pawtograder reviews assign \
  -c cs3500-fall-2026 \
  -a hw-1 \
  --due-date 2026-09-15
```

### Export and modify rubrics

```bash
# Export rubric
pawtograder rubrics export \
  --assignment hw1 \
  --class cs3500 \
  --type grading \
  --output hw1-rubric.yml

# Edit hw1-rubric.yml locally

# Preview changes
pawtograder rubrics import \
  --assignment hw1 \
  --class cs3500 \
  --file hw1-rubric.yml \
  --type grading \
  --dry-run

# Import modified rubric
pawtograder rubrics import \
  --assignment hw1 \
  --class cs3500 \
  --file hw1-rubric.yml \
  --type grading
```

## Troubleshooting

### Authentication issues

If you encounter authentication errors:

1. Verify your token is valid: `pawtograder whoami`
2. Check token scopes match the required permissions (`cli:read` or `cli:write`)
3. For self-hosted deployments, ensure `--url` points at the API gateway origin (e.g. `https://api.your-school.edu`), not the web host

### Repository operations

If git operations fail:

1. Ensure you have SSH access to GitHub: `ssh -T git@github.com`
2. Verify the workdir has sufficient disk space
3. Try reducing `--concurrency` for rate-limited operations

### Getting help

```bash
pawtograder --help
pawtograder assignments --help
pawtograder reviews assign --help
```
