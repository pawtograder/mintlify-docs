# Command Line Interface

The Pawtograder CLI is a command-line tool for instructors and site administrators to automate course management tasks. It provides programmatic access to Pawtograder's core functionality, enabling bulk operations, scripting, and integration with other tools.

## Installation

Install the CLI from npm (requires Node.js 20 or later):

```bash
npm install -g @pawtograder/cli
pawtograder --help
```

Or run it without installing:

```bash
npx @pawtograder/cli --help
```

You can also run it from a clone of the platform repository:

```bash
npm run cli -- <command> [options]
```

## Authentication

Before using the CLI, you must authenticate with an API token.

### Creating an API token

1. Log in to Pawtograder.
2. Navigate to **Settings → API Tokens**.
3. Create a new token with the `cli:read` scope for read commands, or `cli:write` for commands that change data.
4. Copy the generated token (it starts with `mcp_`).

### Logging in

```bash
pawtograder login
```

You will be prompted to enter your API token. The token is stored in `~/.pawtograder/credentials.json`.

You can also provide the token directly:

```bash
pawtograder login --token mcp_your_token_here
```

For self-hosted deployments, point `--url` at your deployment's **API gateway origin** (not the web host):

```bash
pawtograder login --url https://api.your-school.edu
```

### Managing authentication

```bash
# Check current user
pawtograder whoami

# Log out
pawtograder logout
```

## Available commands

### Reading data

Every `list` command accepts `--json` to emit machine-readable output for piping into `jq` or other tools.

| Command | Purpose |
|---------|---------|
| `classes list` / `classes show <id>` | Classes your token can see |
| `assignments list` / `assignments show <id>` | Assignments in a class |
| `submissions list -c <class> -a <assignment>` | Roster with active submission and scores |
| `reviews list -c <class> -a <assignment>` | Review assignments and completion state |
| `discussions list -c <class>` | Discussion topics with thread and question counts |
| `help-requests list -c <class>` | Office-hours help queue |
| `rubrics list` / `rubrics export` | Rubrics, and YAML export |
| `flashcards list` | Flashcard decks |
| `repos list -c <class> -a <assignment>` | Student repositories for an assignment |

### Changing data

| Command | Purpose |
|---------|---------|
| `assignments copy` / `assignments delete` | Copy an assignment between classes; delete one |
| `reviews assign -c <class> -a <assignment> --due-date <date>` | Create review assignments, balanced round-robin over class staff |
| `help-requests close --id <id>` | Close or resolve a help request (instructors only) |
| `rubrics import` | Import a rubric from YAML |
| `flashcards copy` / `surveys copy` | Copy decks or surveys between classes |
| `submissions comments import\|sync` / `submissions artifacts import` | Batch comment and artifact ingestion |

Commands that write accept `--dry-run` where a preview is meaningful.

### Classes

```bash
# List all classes you have access to
pawtograder classes list

# Show details for a specific class
pawtograder classes show <class-id-or-slug>
```

### Assignments

```bash
# List assignments for a class
pawtograder assignments list --class <identifier>

# Show assignment details
pawtograder assignments show <identifier> --class <identifier>

# Copy assignments between classes
pawtograder assignments copy \
  --source-class <slug> \
  --target-class <slug> \
  --all

# Copy with schedule (CSV file with dates)
pawtograder assignments copy \
  --source-class <slug> \
  --target-class <slug> \
  --schedule <file.csv>

# Delete an assignment
pawtograder assignments delete <identifier> \
  --class <identifier> \
  --force
```

#### Assignment copy options

| Option | Description |
|--------|-------------|
| `--source-class` | Source class (ID, slug, or name) |
| `--target-class` | Target class (ID, slug, or name) |
| `--assignment` | Single assignment to copy (ID or slug) |
| `--schedule` | CSV file with assignment slugs/titles and date overrides |
| `--all` | Copy all assignments from the source class |
| `--workdir` | Local directory for git clones (required unless `--skip-repos`) |
| `--dry-run` | Preview changes without making them |
| `--skip-repos` | Skip git repository operations |
| `--skip-rubrics` | Skip rubric copying |
| `--skip-surveys` | Skip survey copying |
| `--concurrency` | Parallel operations (1-8, default 4) |
| `--delay-ms` | Delay between clone batches in milliseconds |

#### Schedule file format

```csv
slug,due_date
hw-01,2026-09-15T23:59:00
hw-02,2026-09-22T23:59:00
project-01,2026-10-01T23:59:00
```

A bare date (`2026-09-15`) means end of that day in the class's time zone. Append a time (`T17:00`) for a specific time, or pass a timestamp with an offset to be explicit.

### Submissions

```bash
# List submissions for an assignment
pawtograder submissions list \
  --class cs3500-fall-2025 \
  --assignment hw1

# Include students who have not submitted
pawtograder submissions list \
  --class cs3500-fall-2025 \
  --assignment hw1 \
  --include-non-submitters
```

#### Import or sync comments

```bash
# Add-only import
pawtograder submissions comments import \
  --class cs3500-spring-2026 \
  --assignment hw1 \
  --file batch-results.json \
  --author-profile-id <uuid>

# Sync (insert new + soft-delete missing)
pawtograder submissions comments sync \
  --class cs3500-spring-2026 \
  --assignment hw1 \
  --file batch-results.json \
  --rubric-part-id <id>
```

#### Import artifacts

```bash
pawtograder submissions artifacts import \
  --class cs3500-spring-2026 \
  --assignment hw1 \
  --file manifest.json \
  --batch-size 5
```

### Reviews

```bash
# List review assignments
pawtograder reviews list \
  --class cs3500-fall-2025 \
  --assignment hw1

# Assign grading work (balanced round-robin)
pawtograder reviews assign \
  --class cs3500-fall-2025 \
  --assignment hw1 \
  --due-date 2026-09-15 \
  --dry-run

# One assignment per rubric part
pawtograder reviews assign \
  --class cs3500-fall-2025 \
  --assignment hw1 \
  --due-date 2026-09-15 \
  --by-part

# Restrict the grader pool
pawtograder reviews assign \
  --class cs3500-fall-2025 \
  --assignment hw1 \
  --due-date 2026-09-15 \
  --grader <profile-id>
```

`reviews assign` balances submissions across active graders and instructors, honoring `grading_conflicts` and never assigning someone their own submission. Re-running is safe — existing assignments are reused rather than duplicated.

For allocations the round-robin cannot express, supply an explicit manifest:

```bash
pawtograder reviews assign \
  --class cs3500-fall-2025 \
  --assignment hw1 \
  --due-date 2026-09-15 \
  --file drafts.json
```

Where `drafts.json` is an array of `{"assignee_profile_id": "...", "submission_id": 123, "rubric_part_id": 45}`.

### Rubrics

```bash
# List rubrics for an assignment
pawtograder rubrics list \
  --assignment <identifier> \
  --class <identifier>

# Export rubric to YAML
pawtograder rubrics export \
  --assignment hw1 \
  --class cs3500-spring-2026 \
  --type grading \
  --output hw1-rubric.yml

# Preview an import without making changes
pawtograder rubrics import \
  --assignment hw1 \
  --class cs3500-spring-2026 \
  --file hw1-rubric.yml \
  --type grading \
  --dry-run

# Apply changes
pawtograder rubrics import \
  --assignment hw1 \
  --class cs3500-spring-2026 \
  --file hw1-rubric.yml \
  --type grading
```

Rubric types: `grading`, `self_review`, `meta`

### Help requests

```bash
# List help requests
pawtograder help-requests list --class cs3500-fall-2025

# Filter by status
pawtograder help-requests list --class cs3500-fall-2025 --status active

# Close a request
pawtograder help-requests close --id <id>
```

Status choices: `open`, `in_progress`, `resolved`, `closed`, `active` (open or in_progress), `all`.

### Discussions

```bash
pawtograder discussions list --class cs3500-fall-2025
```

## Repository maintenance

Repository commands use local SSH git operations. They require SSH access to GitHub and a writable `--workdir`.

### Sync grade workflow

Synchronize `.github/workflows/grade.yml` from the handout repository to all student repositories:

```bash
pawtograder repos sync-grade-workflow \
  --class cs3500-spring-2026 \
  --assignment hw1 \
  --workdir /tmp/pawtograder-repos
```

<Note>
This command is only available for assignments with the autograder enabled. Repo-only assignments (no autograder) have no `grade.yml` to sync.
</Note>

### Cross-assignment copy

Copy files from source assignment repos to target assignment repos after the source due date:

```bash
pawtograder repos copy-after-source-due \
  --class cs3500-spring-2026 \
  --source-assignment hw1 \
  --target-assignment hw2 \
  --workdir /tmp/pawtograder-repos
```

Options:
- `--dry-run` — Preview with rsync -n only
- `--mirror-delete` — Pass rsync --delete (excludes .git)
- `--concurrency <n>` — Parallel operations (1-8, default 2)

## Environment variables

| Variable | Effect |
|----------|--------|
| `PAWTOGRADER_HTTP_TIMEOUT_MS` | Abort requests after this many milliseconds. Unset means no timeout. Raise it for large artifact imports. |
| `PAWTOGRADER_VERBOSE=1` | Log each request and its timing to stderr. |
| `DEBUG=1` | Same as above, plus stack traces on unexpected errors. |

The CLI does not read `.env` files.

### Copy course to new semester

```bash
# 1. Copy all assignments with repositories
pawtograder assignments copy \
  --source-class cs3500-fall-2025 \
  --target-class cs3500-spring-2026 \
  --all \
  --workdir ~/pawtograder-repos

# 2. Copy surveys
pawtograder surveys copy \
  --source-class cs3500-fall-2025 \
  --target-class cs3500-spring-2026 \
  --all

# 3. Copy flashcard decks
pawtograder flashcards copy \
  --source-class cs3500-fall-2025 \
  --target-class cs3500-spring-2026 \
  --all
```

```bash
# Export the current rubric
pawtograder rubrics export \
  --assignment hw1 \
  --class cs3500 \

  --output hw1-rubric.yml

pawtograder rubrics import \
  --assignment hw1 \
  --class cs3500 \
  --file hw1-rubric.yml \
  --type grading \
  --dry-run

# Apply changes
pawtograder rubrics import \
  --assignment hw1 \
  --class cs3500 \
  --file hw1-rubric.yml \
  --type grading
```

```bash
# Preview a balanced split

  --class cs3500-fall-2025 \
  --assignment hw1 \
  --due-date 2026-09-15 \
  --dry-run

pawtograder reviews assign \
  --class cs3500-fall-2025 \
  --assignment hw1 \
  --due-date 2026-09-15
```

## Troubleshooting

### Authentication issues

If you encounter authentication errors:

1. Verify your token is valid: `pawtograder whoami`
2. Check token scopes match the required permissions (`cli:read` or `cli:write`)
3. For self-hosted deployments, ensure `--url` points at the API gateway origin (e.g. `https://api.your-school.edu`), not the web host

Common HTTP errors:

- **401 Unauthorized** — Token expired or revoked. Log in again.
- **403 Forbidden** — Token lacks required scopes.
- **504 Gateway Timeout** — Operation took too long. Increase `PAWTOGRADER_HTTP_TIMEOUT_MS` or use smaller batches.

### Repository operations

If git operations fail:

1. Ensure you have SSH access to GitHub: `ssh -T git@github.com`
2. Verify the workdir has sufficient disk space
3. Try reducing `--concurrency` for rate-limited operations
