# Assignment Dashboard

The assignment dashboard is the default landing page for each assignment. It provides grading status controls, score statistics, a rubric breakdown report, and the full submissions table — all in one place.

## Accessing the Dashboard

Navigate to any assignment to view its dashboard. The dashboard has two tabs:

- **Dashboard**: Score statistics, rubric breakdown, grading controls, and the submissions table.
- **Grading assigned to me**: Your personal queue of review assignments.

## Grading status panel

At the top of the Dashboard tab, the grading status panel shows:

- **Graded / Total**: How many submissions have a completed review.
- **Released / Total**: How many grades have been released to students.

Three assignment-level actions are available here:

- **Finalize grading**: Marks every eligible submission review complete — those whose required rubric checks are all applied. A confirmation popover shows how many reviews can be finalized and how many have missing required checks. This does not release grades to students.
- **Release all**: Makes grades visible to all students for every submission in the assignment.
- **Unrelease all**: Hides grades from all students (reverses Release all).

For per-submission release and unrelease, select rows in the submissions table below and use the **Release** / **Unrelease** buttons that appear.

## Score statistics

The score statistics section shows min, average, and max for:

- **Total score**
- **Autograder score**
- **Submissions per student**

Each metric includes a sparkline histogram. Use the **Filter** dropdown to scope statistics to a specific class section or lab section.

Click **Show detailed distributions** to expand full-size histograms for all three metrics.

## Rubric breakdown

The **Rubric breakdown** section is collapsed by default. Click to expand it and load the rubric report.

The rubric report shows how often each rubric check was applied across a cohort of submissions. Use it to identify common mistakes, calibrate grading, and understand class-wide performance patterns.

### Cohort and filter

By default the cohort is all submissions. Use the **Quick filter** dropdown to scope to a specific criterion or check. For more complex cohorts, click **Advanced filter** to build an AND/OR/NOT filter tree using predicates like:

- **Check applied**: Submissions where a specific check was applied
- **Option selected**: Submissions where a specific option of a choice check was selected
- **Class section** / **Lab section**: Submissions from a specific section
- **Score ≥ / Score ≤**: Submissions within a score range

### Visualizations

Switch between four views using the buttons in the toolbar:

- **Bars** (default): A horizontal bar per check showing the application rate across the cohort.
- **Options**: For choice-style checks, shows the distribution across each option.
- **Table**: A compact table of check names, applied counts, and percentages.
- **By section**: A heatmap comparing application rates across class sections.

### Filtering the submissions table

Click any bar, option row, or table row to filter the submissions table below to the students in that cohort. A banner above the table shows the active filter and a **Clear filter** button.

You can also click **Filter table to these N** in the toolbar to apply the entire current cohort filter to the submissions table.

### Exporting

Click **Export CSV** to download the current view as a CSV file.

### Saving a shared default view

Instructors can save the current filter, visualization, and included checks as the shared default for all staff. Click **Save as default** and confirm the popover warning (the view is shared — all staff will see it). The provenance line below the toolbar shows who saved the default and when.

To reset to the saved default, click **Reset to default**.

## Submissions table

The submissions table lists all students who have made a submission. Columns include submission time, autograder score, total score, grader name, and release status.

Select rows using the checkboxes to release or unrelease grading for specific submissions.

<Note>
Only students who have made a submission appear in the table. To see every student's repository status, visit the **Repository Status** page.
</Note>

## Export controls

The **Export grades** and **Download all** buttons appear in the assignment header (visible to instructors). Use them to download grade data or all submission files for the assignment.

## Integration with other features

The assignment dashboard integrates with:

- [Security Dashboard](/staff/assignments/security-dashboard): Academic integrity monitoring
- [Test Insights](/staff/assignments/test-insights): Student performance analytics
- [Grading Assignments](/staff/assignments/grading-assignments): Task distribution and management

<Tip>
Save a rubric breakdown view as the shared default to give your entire grading team a consistent starting point for reviewing class-wide performance.
</Tip>
