# Assignment Dashboard

The assignment dashboard is the default landing page for each assignment. It gives instructors a real-time view of grading progress, score distributions, and rubric application rates — all in one place.

## Accessing the dashboard

Navigate to any assignment. The **Dashboard** tab is selected by default. The **Grading assigned to me** tab shows only the submissions assigned to the signed-in grader.

## Grading status panel

The top of the dashboard shows a compact grading status bar:

- **Graded / Total**: How many submission reviews have been marked complete.
- **Released / Total**: How many reviews have been released to students.

Three bulk actions are available directly from this panel:

| Action | What it does |
| --- | --- |
| **Finalize grading** | Marks every eligible review complete — those whose required rubric checks are all applied. Reviews with missing required checks are skipped. A preview popover shows how many reviews will be finalized before you confirm. |
| **Release all** | Releases every submission review in the assignment, making grades visible to all students. Requires confirmation. |
| **Unrelease all** | Hides grades from all students (reverses Release all). Requires confirmation. |

<Note>
Finalize grading does **not** release grades to students. Use **Release all** (or per-row release in the submissions table) as a separate step.
</Note>

## Score statistics

The score statistics section shows min, average, and max scores for:

- **Total score** (autograder + hand-grading combined)
- **Autograder score**
- **Submissions per student** (how many times each student submitted)

Each tile includes a sparkline histogram so you can spot the distribution at a glance.

### Section filter

Use the **Filter** dropdown to restrict statistics to a specific class section or lab section. The filter applies to both the stat tiles and the detailed distributions.

### Detailed distributions

Click **Show detailed distributions** to expand full-size histograms for all three metrics, along with a table showing min/max/average/count for each.

## Rubric breakdown

The **Rubric breakdown** section (collapsed by default) shows how often each rubric check was applied across the cohort of submissions. Expand it by clicking the section header.

### Cohort and filter

By default the cohort is all submissions. Use the **Quick filter** dropdown to instantly scope the cohort to a specific criterion or check. For more complex cohorts, click **Advanced filter** to build an AND/OR/NOT filter tree using predicates such as:

- **Check applied** — submissions where a specific check was applied
- **Option selected** — submissions where a specific sub-option of a choice check was selected
- **Class section** / **Lab section** — submissions from a specific section
- **Score ≥ / Score ≤** — submissions within a score range

The cohort total is shown next to the filter controls.

### Visualizations

Switch between four views using the button group:

| View | Description |
| --- | --- |
| **Bars** | Horizontal progress bars showing application rate per check, grouped by criterion |
| **Options** | Per-option breakdown for choice-style checks (checks with multiple point options) |
| **Table** | Tabular view with applied count and percentage per check |
| **By section** | Heatmap comparing application rates across class sections |

### Drilling into the submissions table

Click any bar, option row, or table row to filter the submissions table below to the students in that cohort. A banner above the table shows the active filter and a **Clear filter** button.

You can also click **Filter table to these N** to push the current cohort filter to the submissions table.

### Exporting

Click **Export CSV** to download the current view (cohort + selected checks + visualization) as a CSV file.

### Saving a shared default view

Instructors can save the current rubric breakdown configuration (filter, visualization, and included checks) as the shared default for all staff:

1. Configure the filter and visualization you want all staff to see by default.
2. Click **Save as default**.
3. Confirm in the popover — this updates the view for everyone on the course staff.

The provenance line below the filter controls shows who saved the current default and when. Click **Reset to default** to revert your local view to the saved default.

<Note>
The saved default is shared across all staff. Graders can see it but cannot overwrite it — only instructors can save a new default.
</Note>

### Rubric items selector

Click **Rubric items (N/total)** to expand a multi-tier selector that lets you include or exclude specific checks from the breakdown. Toggle individual checks, entire criteria, or entire rubric parts. Changes apply immediately to the visualization.

## Submissions table

Below the statistics and rubric breakdown is the full submissions table, showing every student who has made a submission. The table supports:

- **Column visibility**: Toggle columns on/off from the column controls.
- **Filtering**: Filter by grader, section, submission status, and more.
- **Row selection**: Select submissions with checkboxes to release or unrelease their grading in bulk.
- **Cohort filter**: When a rubric breakdown cohort is active, the table is automatically filtered to matching students.

For per-row release/unrelease and other bulk operations, see [Bulk Actions](/staff/assignments/bulk-actions).

## Export controls

The **Export grades** and **Download all** buttons appear in the assignment header (visible to instructors). Use them to download grade data or all submission files for the assignment.
