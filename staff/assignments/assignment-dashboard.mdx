# Assignment Dashboard

The assignment dashboard is the default landing page for each assignment. It gives instructors and graders a single place to track grading progress, review score distributions, and drill into rubric-check application rates.

## Accessing the dashboard

Navigate to any assignment. The **Dashboard** tab is selected by default. Graders also see a **Grading assigned to me** tab showing only their own queue.

## Grading status panel

At the top of the dashboard, the grading status panel shows:

- **Graded / total** — how many submission reviews have been completed.
- **Released / total** — how many grades are visible to students.

Three bulk actions are available from this panel:

| Action | What it does |
|---|---|
| **Finalize grading** | Marks every eligible review complete — those where all required rubric checks have been applied. Shows a preview of how many reviews will be finalized before you confirm. Does not release grades to students. |
| **Release all** | Makes grades visible to all students for every submission in the assignment. Requires confirmation. |
| **Unrelease all** | Hides grades from all students (reverses Release all). Requires confirmation. |

Per-submission release and unrelease are still available in the submissions table below by selecting rows.

## Score statistics

The score statistics section shows compact stat tiles for:

- **Total score** — the combined autograder + handgrading score.
- **Autograder score** — the autograder component only.
- **Submissions / student** — how many attempts each student has made.

Each tile shows the average, min–max range, count of graded submissions, and a sparkline histogram. Click **Show detailed distributions** to expand full-size histograms for all three metrics.

### Section filter

Use the **Filter** dropdown to scope all statistics to a specific class section or lab section. The filter applies to both the stat tiles and the rubric breakdown.

## Rubric breakdown

The **Rubric breakdown** panel is collapsed by default. Expand it to see how often each rubric check was applied across the cohort of submissions.

### Visualizations

Switch between four views using the buttons in the panel header:

| View | Description |
|---|---|
| **Bars** | Horizontal progress bars showing the application rate for each check, grouped by criterion. |
| **Options** | For choice-style checks, shows the distribution across each option. |
| **Table** | Compact table of check name, applied count, and percentage. |
| **By section** | Heatmap comparing application rates across class sections. |

### Filtering the cohort

Two filter controls let you define which submissions are included in the breakdown:

- **Quick filter** — a dropdown to instantly scope to a single criterion or check.
- **Advanced filter** — a nestable AND/OR/NOT builder supporting predicates: check applied, option selected, class section, lab section, score ≥, score ≤.

The panel header shows the cohort size (number of submissions matching the current filter).

### Drilling into submissions

Click any bar, option row, or table row — or use the **Filter table to these N** button — to filter the submissions table below to only the students in that cohort. A banner above the table shows the active filter; click **Clear filter** to reset.

### Exporting

Click **Export CSV** to download the current view (cohort + selected checks + visualization) as a CSV file.

### Saving a shared default view

Instructors can save the current filter and visualization as the shared default that all staff see when they open the rubric breakdown. Click **Save as default** (a confirmation popover warns that this is a shared view). Staff can click **Reset to default** to restore the saved view after making local changes.

The panel footer shows who saved the current default and when.

## Submissions table

Below the statistics and rubric breakdown, the full submissions table lists every student who has made a submission. Columns include student name, score, grader, submission time, and release status.

- Select rows to release or unrelease individual submissions.
- Use the column visibility controls to show or hide columns.
- The **Export grades** and **Download all** buttons in the assignment header apply to the whole assignment.

<Note>
Only students who have made at least one submission appear in this table. To see every student's repository status, use the **Repository Status** link shown above the table.
</Note>
