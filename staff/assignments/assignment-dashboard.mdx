# Assignment Dashboard

The assignment dashboard is the default landing page for each assignment. It provides grading status controls, score statistics, a rubric breakdown report, and the full submissions table — all in one place.

## Accessing the dashboard

Navigate to any assignment to view its dashboard. The **Dashboard** tab is shown by default; the **Grading assigned to me** tab shows only the submissions assigned to you.

## Grading status panel

The top of the dashboard shows a summary of grading progress and provides assignment-level bulk actions:

- **Graded / Released counts** — how many submissions have completed reviews and how many have been released to students.
- **Finalize grading** — marks every eligible submission review complete (those whose required rubric checks are all applied). This does not release grades to students. A confirmation popover shows how many reviews can be finalized and how many are blocked by missing required checks.
- **Release all** — makes grades visible to all students for every submission in the assignment.
- **Unrelease all** — hides grades from all students (reverses Release all).

Per-submission release and unrelease remain available in the submissions table by selecting rows and using the **Release** / **Unrelease** buttons that appear.

## Score statistics

The statistics section shows min, max, and average scores for the assignment, with sparkline histograms for a quick visual overview. Use the **Filter** dropdown to scope the statistics to a specific class section or lab section.

Click **Show detailed distributions** to expand full-size histograms for total score, autograder score, and submissions per student.

## Rubric breakdown

The **Rubric breakdown** section (collapsed by default) shows how often each rubric check was applied across a cohort of submissions. Expand it to access the report.

### Cohort and filter

By default the cohort is all submissions. Use the **Quick filter** dropdown to instantly scope the cohort to a criterion or a specific check. For more complex cohorts, expand **Advanced filter** to build an AND/OR/NOT filter tree using predicates such as:

- **Check applied** — submissions where a specific rubric check was applied
- **Option selected** — submissions where a specific option of a choice check was selected
- **Class section / Lab section** — submissions from a specific section
- **Score ≥ / Score ≤** — submissions within a score range

### Visualizations

Switch between four views using the buttons in the toolbar:

| View | Description |
| --- | --- |
| **Bars** | Horizontal progress bars showing the application rate for each check, grouped by criterion |
| **Options** | Per-option breakdown for choice-style checks |
| **Table** | Tabular view of check name, applied count, and percentage |
| **By section** | Heatmap comparing application rates across class sections |

### Drilling into the submissions table

Click any bar, option row, or table row to filter the submissions table below to the students in that cohort. The **Filter table to these N** button applies the entire current cohort filter. A banner above the table shows the active filter; click **Clear filter** to reset.

### Exporting

Click **Export CSV** to download the current view (cohort + selected checks + visualization) as a CSV file.

### Rubric items selector

Click **Rubric items** to choose which checks appear in the report. You can include or exclude individual checks, entire criteria, or entire rubric parts. **Select all** and **Clear** buttons are available for quick bulk selection.

### Saving a shared default view

Instructors can save the current filter, visualization, and rubric item selection as the shared default for all staff. Click **Save as default** (a confirmation popover warns that this is a shared view visible to all staff). The provenance of the saved view — who saved it and when — is shown below the toolbar.

Staff can click **Reset to default** to restore the saved default at any time.

## Submissions table

The submissions table below the rubric breakdown shows all submissions for the assignment. When a rubric-report cohort filter is active, the table is restricted to matching students.

### Exporting grades and downloading submissions

The **Export grades** and **Download all** buttons appear in the assignment page header (visible to instructors). Use **Export grades** to download a CSV of scores and grading data; use **Download all** to download all submission files as a ZIP.
