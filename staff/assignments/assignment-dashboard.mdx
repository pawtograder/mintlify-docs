# Assignment Dashboard

The assignment dashboard provides a centralized view of all key metrics and information for an assignment. Use it to monitor student progress, track grading, and analyze rubric application patterns.

## Accessing the Dashboard

Navigate to any assignment to view its dashboard — it is the default landing page for each assignment. The dashboard has two tabs:

- **Dashboard** — score statistics, grading status, rubric breakdown, and the submissions table.
- **Grading assigned to me** — your personal queue of incomplete review assignments.

## Grading status panel

At the top of the Dashboard tab, a status panel shows:

- **Graded / total** — how many submission reviews have been marked complete.
- **Released / total** — how many grades have been released to students.

Three bulk actions are available directly from this panel:

| Action | What it does |
|---|---|
| **Finalize grading** | Marks every eligible review complete — those where all required rubric checks are applied. Shows a preview of how many reviews will be finalized and how many will be skipped due to missing required checks. Does **not** release grades. |
| **Release all** | Makes grades visible to all students for every submission in the assignment. |
| **Unrelease all** | Hides grades from all students (reverses Release all). |

## Score statistics

The score statistics section shows min, average, and max for:

- **Total score** — combined autograder + hand-grading score.
- **Autograder score** — autograder points only.
- **Submissions per student** — how many attempts each student made.

Each metric includes a sparkline histogram. Click **Show detailed distributions** to expand full-size histograms.

### Section filter

Use the **Filter** dropdown to restrict statistics and the submissions table to a specific class section or lab section.

## Rubric breakdown

The **Rubric breakdown** section (collapsed by default) shows how often each rubric check was applied across the cohort of submissions. Expand it to access:

- **Visualization modes** — Bars (default), Options, Table, or By section.
- **Quick filter** — jump to a specific criterion or check.
- **Advanced filter** — build AND/OR/NOT filter trees over check application, option selection, section, lab, score range, and more.
- **Rubric items** — choose which checks appear in the report.
- **Export CSV** — download the current view.
- **Filter table to these N** — restrict the submissions table below to the students matching the current rubric filter.

### Shared default view

Instructors can save the current rubric breakdown configuration (visualization mode, filter, and selected checks) as the **shared default** for all staff on this assignment. Click **Save as default** and confirm the popover warning that this affects all staff. Graders see the saved default when they open the rubric breakdown; they can reset to it at any time with **Reset to default**.

## Submissions table

Below the statistics and rubric breakdown, the submissions table lists every student who has made a submission. From here you can:

- Select rows and use **Release** / **Unrelease** to act on specific submissions.
- Use **Export grades** and **Download all** (in the page header) to export data.
- Filter by grader, section, completion status, and more.

When a rubric filter is active, a banner above the table shows how many students match and provides a **Clear filter** button.

<Note>
Only students who have made a submission appear in the table. To see every student's repository status, visit the **Repository Status** page.
</Note>
