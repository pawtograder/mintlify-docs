# Assignment Dashboard

The assignment dashboard is the default landing page for each assignment. It provides a centralized view of grading progress, score statistics, a rubric breakdown, and the full submissions table.

## Accessing the Dashboard

Navigate to any assignment to view its dashboard. The dashboard is the first tab (**Dashboard**); the second tab (**Grading assigned to me**) shows only the submissions assigned to you for grading.

## Grading status panel

At the top of the dashboard, the grading status panel shows:

- **Graded / Total**: How many submission reviews have been marked complete out of the total.
- **Released / Total**: How many reviews have been released to students.

The panel also provides three assignment-level grading actions:

- **Finalize grading** — marks every eligible submission review complete (those whose required rubric checks are all applied). Shows an eligibility preview before confirming. This does not release grades to students.
- **Release all** — makes grades visible to all students for every submission in the assignment.
- **Unrelease all** — hides grades from all students (reverses Release all).

For per-submission release and unrelease, select rows in the submissions table and use the **Release** / **Unrelease** buttons that appear in the toolbar.

## Score statistics

The score statistics section shows compact stat tiles for:

- **Total score** — the combined autograder + hand-grading score
- **Autograder score** — the automated test score alone
- **Submissions per student** — how many times each student has submitted

Each tile shows the average, min–max range, count, and a sparkline histogram. Click **Show detailed distributions** to expand full histograms for each metric.

Use the **Filter** dropdown to restrict statistics to a specific class section or lab section.

## Rubric breakdown

The **Rubric breakdown** section (collapsed by default) shows how often each rubric check was applied across the cohort of submissions. Expand it to access:

- **Bars view** — a horizontal bar for each check showing the application rate.
- **Options view** — for choice-style checks, a bar per option showing how often each option was selected.
- **Table view** — a compact table of check names, applied counts, and percentages.
- **By section view** — a heatmap comparing application rates across class sections.

### Filtering the cohort

Use the **Quick filter** dropdown to instantly scope the report to a specific criterion or check. For more complex filters, expand **Advanced filter** to build an AND/OR/NOT tree over predicates including:

- Check applied / option selected
- Class section / lab section
- Score at least / score at most

### Filtering the submissions table

Click any bar, option, or table row — or use the **Filter table to these N** button — to filter the submissions table below to the students matching that cohort. A banner above the table shows the active filter; click **Clear filter** to reset.

### Saving a shared default view

Instructors can save the current rubric breakdown configuration (visualization type, filter, and selected checks) as the shared default for all staff. Click **Save as default** and confirm the popover. All staff will see this view when they open the rubric breakdown. Use **Reset to default** to revert your local view to the saved default.

## Submissions table

The submissions table lists every student who has made a submission. From here you can:

- Click a student name to open their submission for grading.
- Select rows with checkboxes and use the **Release** / **Unrelease** toolbar to act on a subset of submissions.
- Use the column visibility controls to show or hide columns.
- Export grades or download all submissions using the **Export grades** and **Download all** buttons in the assignment header (visible to instructors).

Students who have not submitted do not appear in this table. To see every student's repository status, visit the [Repository Status](/staff/assignments/repository-analytics) page.

## Integration with other features

The assignment dashboard integrates with:

- [Grading Status](/staff/assignments/grading-status): Detailed per-grader progress tracking
- [Security Dashboard](/staff/assignments/security-dashboard): Academic integrity monitoring
- [Test Insights](/staff/assignments/test-insights): Student performance analytics
- [Grading Assignments](/staff/assignments/grading-assignments): Task distribution and management

<Tip>
Use the rubric breakdown's **By section** view to quickly spot which sections are struggling with specific checks, then filter the submissions table to those students for targeted follow-up.
</Tip>
