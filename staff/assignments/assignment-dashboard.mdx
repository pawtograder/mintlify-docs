# Assignment Dashboard

The assignment dashboard provides a centralized view of all key metrics and information for an assignment. Use this dashboard to monitor student progress, track submissions, manage grading workflows, and analyze rubric check application rates.

## Accessing the Dashboard

Navigate to any assignment to view its dashboard — it is the default landing page for each assignment. The dashboard tab is shown first; a second tab, **Grading assigned to me**, shows only the reviews assigned to the current user.

## Dashboard Components

### Grading status panel

At the top of the dashboard, the grading status panel shows:

- **Graded / Total**: How many submission reviews have been completed out of the total.
- **Released / Total**: How many grading reviews have been released to students.

Three bulk actions are available directly from this panel:

- **Finalize grading** — Marks every eligible submission review as complete (those with all required rubric checks applied). Shows an eligibility preview before confirming. Does not release grades to students.
- **Release all** — Makes grades visible to all students for every submission in the assignment.
- **Unrelease all** — Hides grades from all students (reverses Release all).

### Score statistics

The score statistics section shows min, average, and max scores with sparkline histograms for:

- **Total score** — The combined autograder + hand-grading score.
- **Autograder score** — Points from the autograder alone.
- **Submissions / student** — How many submission attempts each student has made.

Use the **Filter** dropdown to scope statistics to a specific class section or lab section.

Click **Show detailed distributions** to expand full histograms and per-metric stat cards.

### Rubric breakdown

The **Rubric breakdown** section (collapsed by default) shows how often each rubric check was applied across a cohort of submissions. Expand it to access the rubric report.

#### Rubric report

The rubric report lets you analyze check application rates across your class:

- **Cohort filter** — Use the quick filter dropdown to jump to a criterion or specific check, or use **Advanced filter** to build AND/OR/NOT conditions over check application, option selection, class section, lab section, and score thresholds.
- **Rubric items** — Choose which checks appear in the report using the multi-tier include/exclude selector.
- **Visualization modes** — Switch between **Bars** (application rate per check), **Options** (per-option breakdown for choice checks), **Table** (compact tabular view), and **By section** (heatmap comparing sections).
- **Export CSV** — Download the current view as a CSV file.
- **Filter table to these N** — Click any bar, option row, or table row to filter the submissions table below to only the students in that cohort.

Instructors can save the current rubric report configuration as the **shared default** for all staff using **Save as default**. Graders can read the shared default but cannot overwrite it.

### Submissions table

Below the statistics and rubric breakdown, the submissions table lists all students who have submitted. Only students with at least one submission appear here; to see every student's repository, visit the [Repository Status](/staff/assignments/repository-analytics) page.

When a rubric report cohort filter is active, a banner shows how many students are displayed and provides a **Clear filter** button to return to the full list.

Select submissions using the checkboxes to **Release** or **Unrelease** their grading reviews individually.

Export controls (**Export grades** and **Download all**) appear in the assignment page header for instructors.

## Integration with Other Features

The assignment dashboard integrates with:

- [Grading Status](/staff/assignments/grading-status): Detailed grading progress tracking
- [Security Dashboard](/staff/assignments/security-dashboard): Academic integrity monitoring
- [Test Insights](/staff/assignments/test-insights): Student performance analytics
- [Grading Assignments](/staff/assignments/grading-assignments): Task distribution and management

## Best Practices

- **Use section filters** to compare score distributions across class or lab sections.
- **Open the rubric breakdown** after grading is complete to identify checks that were rarely or frequently applied — useful for calibrating future rubrics.
- **Save a rubric report default** so all graders see the same view when they open the dashboard.
- **Finalize grading** before releasing to catch any submissions missing required rubric checks.

<Tip>
Click any bar or row in the rubric breakdown to filter the submissions table to just the students in that cohort, making it easy to follow up with specific groups.
</Tip>
