# Assignment Dashboard

The assignment dashboard provides a centralized view of all key metrics and information for an assignment. Use this dashboard to monitor student progress, track submissions, and manage assignment logistics and grading workflows.

## Accessing the Dashboard

Navigate to any assignment to view its dashboard — it is the default landing page for each assignment. For a course-wide view of all assignments, access the assignment dashboard from the course navigation.

## Dashboard components

### Grading status panel

The top of the dashboard shows a compact grading status panel with:

- **Graded / total**: How many submission reviews have been marked complete.
- **Released / total**: How many reviews have been released to students.
- **Finalize grading**: Marks every eligible submission review complete in one step. A confirmation popover shows how many reviews can be finalized and how many are blocked by missing required rubric checks.
- **Release all / Unrelease all**: Bulk-release or bulk-unrelease all grading reviews for the assignment with a confirmation step.

Per-submission release and unrelease remain available in the submissions table below by selecting rows and using the contextual toolbar.

### Score statistics

The score statistics section shows compact stat tiles for **Total score**, **Autograder score**, and **Submissions per student**, each with a sparkline distribution chart. Use the **Filter** dropdown to scope the stats to a specific class section or lab section.

Click **Show detailed distributions** to expand full histograms and min/max/average breakdowns for each metric.

### Rubric breakdown

The **Rubric breakdown** panel (collapsed by default) shows how often each rubric check was applied across a cohort of submissions. Use it to identify common mistakes, calibrate grading, or compare performance across sections.

#### Visualizations

| Mode | Description |
| --- | --- |
| **Bars** (default) | Horizontal application-rate bars grouped by criterion |
| **Options** | Per-option breakdown for choice-style checks |
| **Table** | Compact tabular view with applied count and percentage |
| **By section** | Heatmap comparing application rates across class sections |

#### Filtering the cohort

Use the **Quick filter** dropdown to instantly scope the cohort to a criterion or a specific check. For more complex queries, click **Advanced filter** to build a nested AND/OR/NOT filter over:

- Check applied / option selected
- Class section / lab section
- Score at least / score at most

#### Rubric items selector

Click **Rubric items** to choose which checks appear in the report. You can include or exclude individual checks, entire criteria, or whole rubric parts.

#### Drilling into the submissions table

Click any bar, option row, or table row — or use the **Filter table to these N** button — to filter the submissions table below to the students matching that cohort. A banner above the table shows the active filter; click **Clear filter** to reset.

#### Saving a shared default view

Instructors can click **Save as default** to persist the current visualization, filter, and rubric-item selection as the shared default for all staff on this assignment. A confirmation popover warns that this is a shared view. The provenance (saved by whom and when) is shown below the toolbar. Any staff member can click **Reset to default** to restore the saved view.

### Submissions table

The submissions table lists every student who has made a submission. Select rows to release or unrelease their grading reviews. Use **Export grades** and **Download all** (in the page header) to export data for the whole assignment.

Students who have not submitted do not appear here. To see every student's repository status, visit the **Repository Status** page.

## Best Practices

- **Check regularly**: Review the dashboard at least weekly to stay informed.
- **Act on alerts**: Address flagged issues promptly to support student success.
- **Use filters**: Focus on specific assignment types or time periods for targeted analysis.
- **Export data**: Download reports for deeper analysis or record-keeping.
- **Share insights**: Use dashboard data to inform teaching team discussions.
