# Assignment Dashboard

The assignment dashboard provides a centralized view of all key metrics and information for an assignment. Use it to monitor student progress, track submissions, manage grading workflows, and analyze rubric check application rates.

## Accessing the Dashboard

Navigate to any assignment to view its dashboard — it is the default landing page for each assignment. The dashboard has two tabs:

- **Dashboard** — score statistics, grading status, rubric breakdown, and the submissions table.
- **Grading assigned to me** — your personal grading queue.

## Dashboard Components

### Grading status panel

At the top of the dashboard, a compact panel shows:

- **Graded / Total** — how many submission reviews have been completed.
- **Released / Total** — how many grades have been released to students.
- **Finalize grading** — marks every eligible submission review complete (those whose required rubric checks are all applied). This does not release grades to students.
- **Release all** — makes grades visible to all students for every submission in this assignment.
- **Unrelease all** — hides grades from all students (reverses Release all).

### Score statistics

The statistics section shows min, average, and max scores for:

- **Total score** — the combined autograder + hand-grading score.
- **Autograder score** — the automated test score alone.
- **Submissions / student** — how many attempts each student has made.

Each tile includes a sparkline histogram. Click **Show detailed distributions** to expand full histograms.

Use the **Filter** dropdown to scope statistics to a specific class section or lab section.

### Rubric breakdown

Click **Rubric breakdown** to expand the rubric report panel. This panel shows how often each rubric check was applied across the cohort of submissions.

#### Visualizations

Switch between four views using the toolbar buttons:

| View | Description |
|---|---|
| **Bars** | Horizontal bar per check showing application rate (default). |
| **Options** | For choice-style checks, shows per-option application rates. |
| **Table** | Tabular view of check name, applied count, and percentage. |
| **By section** | Heatmap comparing application rates across class sections. |

#### Filtering the cohort

Use the **Quick filter** dropdown to instantly scope the report to a single criterion or check. For more complex filters, click **Advanced filter** to build AND/OR/NOT trees over predicates such as:

- Check applied / option selected
- Class section / lab section
- Score ≥ / Score ≤

#### Drilling into submissions

Click any bar, option row, or table row to filter the submissions table below to the students whose submission matches that check. Click **Filter table to these N** to apply the current cohort filter to the submissions table. Click **Clear filter** in the submissions table to reset.

#### Exporting

Click **Export CSV** to download the current rubric report view as a CSV file.

#### Shared default view

Instructors can save the current rubric report configuration (visualization, filter, and included checks) as the shared default for all staff. Click **Save as default** and confirm. All staff will see this view when they open the rubric breakdown. Graders can read the shared default but cannot overwrite it.

### Submissions table

Below the rubric breakdown, the submissions table lists every student who has submitted. Columns include student name, grader, score, submission time, and release status.

Select rows using the checkboxes, then use the **Release** or **Unrelease** buttons to act on only the selected submissions.

Use **Export grades** and **Download all** (in the page header) to export data for the whole assignment.

## Best Practices

- **Check the grading status panel** before releasing grades to confirm all reviews are complete.
- **Use the rubric breakdown** after grading to identify checks that were rarely or never applied — these may indicate unclear rubric criteria.
- **Save a shared default view** for the rubric breakdown so your whole team sees the same analysis when they open the dashboard.
- **Filter by section** to compare performance across lab or class sections.
