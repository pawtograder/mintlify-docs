# Assignment Dashboard

The assignment dashboard provides a centralized view of all key metrics and information for an assignment. Use this dashboard to monitor student progress, track submissions, and manage assignment logistics and grading workflows.

## Accessing the Dashboard

Navigate to any assignment to view its dashboard — it is the default landing page for each assignment. For a course-wide view of all assignments, access the assignment dashboard from the course navigation.

## Dashboard tabs

The assignment home page has two tabs:

- **Dashboard** — the default view, described below.
- **Grading assigned to me** — shows only the submissions assigned to the current grader for review.

## Dashboard components

### Grading status panel

The top of the dashboard shows a compact grading status bar with:

- **Graded / total**: How many submission reviews have been marked complete.
- **Released / total**: How many reviews have been released to students.
- **Finalize grading**: Marks every eligible submission review complete (those whose required rubric checks are all applied). This does not release grades to students.
- **Release all** / **Unrelease all**: Bulk-release or bulk-unrelease all grading reviews for the assignment, with a confirmation step.

Per-submission release and unrelease remain available in the submissions table below by selecting rows.

### Score statistics

Compact stat tiles show **min / average / max** and a sparkline histogram for:

- **Total score**
- **Autograder score**
- **Submissions per student**

Use the **Filter** dropdown to scope statistics to a specific class section or lab section.

Click **Show detailed distributions** to expand full histograms for each metric.

### Rubric breakdown

The **Rubric breakdown** section (collapsed by default) shows how often each rubric check was applied across a cohort of submissions. It is instructor-only and loads on first open.

#### Visualizations

Switch between four views using the buttons in the toolbar:

| View | Description |
| --- | --- |
| **Bars** | Horizontal progress bars showing the application rate per check, grouped by criterion. |
| **Options** | Per-option breakdown for choice-style checks (checks with multiple point options). |
| **Table** | Tabular view of check name, applied count, and percentage. |
| **By section** | Heatmap comparing application rates across class sections. |

#### Cohort filtering

By default the cohort is all students with an active submission. Use the **Quick filter** dropdown to instantly scope to a criterion or a specific check. For more complex filters, expand **Advanced filter** to build AND/OR/NOT trees over predicates including:

- Check applied / option selected
- Class section / lab section
- Score at least / score at most

Click any bar, option row, or table row to filter the submissions table below to the matching students. Use **Filter table to these N** to apply the current cohort filter to the table.

#### Saved default view

Instructors can save the current filter + visualization as the **shared default** for all staff on this assignment. Click **Save as default** (a confirmation popover warns that this is a shared view). Any staff member can click **Reset to default** to restore the saved view. The provenance (saved by whom and when) is shown below the toolbar.

Export the current view as CSV with **Export CSV**.

### Submissions table

The submissions table lists all students who have made at least one submission. Select rows to release or unrelease their grading reviews. Use the **Export grades** and **Download all** buttons in the page header to export data for the whole assignment.

<Note>
Only students who have made a submission appear in the table. To see every student's repository status, visit the **Repository Status** page.
</Note>

### Quick actions

Export controls (**Export grades**, **Download all**) appear in the assignment page header for instructors.

## Integration with other features

The assignment dashboard integrates with:

- [Grading Status](/staff/assignments/grading-status): Detailed grading progress tracking
- [Security Dashboard](/staff/assignments/security-dashboard): Academic integrity monitoring
- [Test Insights](/staff/assignments/test-insights): Student performance analytics
- [Grading Assignments](/staff/assignments/grading-assignments): Task distribution and management

<Tip>
Open the rubric breakdown and save a default view at the start of grading to give all TAs a consistent starting point for reviewing check application rates.
</Tip>
