# Assignment Dashboard

The assignment dashboard provides a centralized view of all key metrics and information for an assignment. Use this dashboard to monitor student progress, track submissions, and manage assignment logistics and grading workflows.

## Accessing the Dashboard

Navigate to any assignment to view its dashboard — it is the default landing page for each assignment. For a course-wide view of all assignments, access the assignment dashboard from the course navigation.

## Dashboard Components

### Grading status panel

The top of the dashboard shows a summary of grading progress and provides assignment-level bulk actions:

- **Graded / Released counts** — how many submissions have completed reviews and how many have been released to students.
- **Finalize grading** — marks every eligible submission review complete in one step. Before confirming, a preview shows how many reviews can be finalized and how many are blocked by missing required rubric checks.
- **Release all** — releases grades for every submission in the assignment, making them visible to all students. Requires confirmation.
- **Unrelease all** — hides grades from all students (reverses a release). Requires confirmation.

Per-submission release and unrelease controls remain in the submissions table below.

### Score statistics

The score statistics section shows min, max, and average scores for the assignment, with sparkline charts for a quick visual overview. You can filter by class section or lab section using the dropdown.

Expand **Show detailed distributions** to see full histograms for:

- **Total score** — the combined autograder + hand-grading score.
- **Autograder score** — the automated test score alone.
- **Submissions per student** — how many times each student submitted.

### Rubric breakdown

The **Rubric breakdown** section (collapsed by default) shows how often each rubric check was applied across the cohort of submissions. Use it to identify common mistakes, calibrate grading, or spot checks that were rarely or never applied.

Features include:

- **Quick filter** — jump to a specific criterion or check to see its application rate.
- **Advanced filter** — build AND/OR/NOT filters over check application, option selection, class/lab section, and score range to define a custom cohort.
- **Rubric items selector** — choose which checks appear in the view.
- **Visualization modes** — switch between bars (default), options (for choice checks), table, and by-section comparison.
- **Export CSV** — download the current view as a CSV file.
- **Filter table** — click any bar, row, or the "Filter table to these N" button to restrict the submissions table below to the matching students.
- **Save as default** (instructors only) — save the current filter and visualization as the shared default view for all staff on this assignment.

### Submissions table

The submissions table lists all students who have submitted. You can:

- Select rows and use **Release** or **Unrelease** to act on specific submissions.
- Filter by grader, section, or other columns.
- Export grades or download all submissions using the controls in the page header.

Only students who have submitted appear in this table. To see every student's repository status, use the **Repository Status** page.

## Filtering and Sorting

Customize your dashboard view:

- Filter by submission status (submitted, pending, late) or by assignment status (draft, released, closed).
- Sort by score, submission time, student name, due date, or grading progress.
- Search for specific students or assignments.
- Group by section or team (for group assignments) or by assignment type.

## Visual Indicators

The dashboard uses visual cues to highlight important information:

- **Progress bars**: Show grading completion percentage.
- **Status badges**: Indicate assignment state (draft, active, closed).
- **Alert icons**: Flag assignments requiring attention (low submission rates, overdue grading).
- **Color coding**: Differentiate between on-time, late, and missing submissions.

## Using the Dashboard

### Monitoring student progress

1. Review submission rates to identify students who may need support.
2. Check submission timing to understand student work patterns.
3. Monitor late submission trends to adjust deadlines if needed.
4. Identify assignments with low engagement for intervention.

### Managing grading workflows

1. View which assignments need grading assignments.
2. Track grading progress and identify bottlenecks.
3. Ensure timely grade release to students.
4. Balance grading workload across staff members.

### Assignment planning

Use dashboard insights to improve future assignments:

- Analyze submission patterns to optimize due dates.
- Review average scores to calibrate difficulty.
- Identify assignments that need clarification based on submission rates.
- Track time-to-completion for better scheduling.

## Exporting Data

## Best Practices

- **Check regularly**: Review the dashboard at least weekly to stay informed.
- **Act on alerts**: Address flagged issues promptly to support student success.
- **Use filters**: Focus on specific assignment types or time periods for targeted analysis.
- **Export data**: Download reports for deeper analysis or record-keeping.
- **Share insights**: Use dashboard data to inform teaching team discussions.
