# Assignment Dashboard

The assignment dashboard is the default landing page for each assignment. It gives instructors and graders a single place to monitor grading progress, review score statistics, explore rubric breakdowns, and act on submissions.

## Accessing the dashboard

Navigate to any assignment from the course navigation. The **Dashboard** tab is shown by default. Graders also see a **Grading assigned to me** tab listing only their own assigned submissions.

## Grading status panel

At the top of the dashboard, the grading status panel shows:

- **Graded / Total** — how many submission reviews have been completed.
- **Released / Total** — how many completed reviews have been released to students.

Three assignment-level actions are available here:

| Action | What it does |
|---|---|
| **Finalize grading** | Marks every eligible review complete — those where all required rubric checks have been applied. Shows a preview of how many reviews will be finalized before you confirm. Does **not** release grades to students. |
| **Release all** | Makes grades visible to all students for every submission in the assignment. Requires confirmation. |
| **Unrelease all** | Hides grades from all students again (reverses Release all). Requires confirmation. |

To release or unrelease individual submissions, select rows in the submissions table below and use the contextual **Release** / **Unrelease** buttons that appear.

## Score statistics

The score statistics section shows summary stats for the assignment, filterable by class section or lab section:

- **Total score** — min, average, max, and count across graded submissions, with a sparkline histogram.
- **Autograder score** — same breakdown for the autograder component.
- **Submissions / student** — distribution of how many attempts each student has made.

Click **Show detailed distributions** to expand full histograms for each metric.

Use the **Filter** dropdown to scope statistics to a specific class section or lab section.

## Rubric breakdown

The **Rubric breakdown** section (collapsed by default) shows how often each rubric check was applied across a cohort of submissions. Expand it to:

- See application rates for every check, grouped by criterion.
- Switch between **Bars**, **Options**, **Table**, and **By section** visualizations.
- Use the **Quick filter** dropdown to focus on a specific criterion or check.
- Build advanced AND/OR/NOT filters with the **Advanced filter** panel.
- Use **Rubric items** to include or exclude specific checks from the view.
- Click any bar, option, or row to filter the submissions table below to the matching students.
- Click **Filter table to these N** to apply the current cohort as a submissions table filter.
- Click **Export CSV** to download the current view.

Instructors can click **Save as default** to persist the current visualization and filter as the shared default for all staff on this assignment. The saved default shows who saved it and when. Any staff member can click **Reset to default** to restore the shared view.

## Submissions table

The submissions table lists every student who has made a submission. Columns include student name, grader, score, submission time, and release status.

- Select rows to reveal contextual **Release** / **Unrelease** buttons for those submissions.
- Use column visibility controls to show or hide fields.
- Filter by grader, section, or other attributes.

When a rubric breakdown cohort filter is active, a banner above the table shows how many students are displayed and provides a **Clear filter** button.

Students who have not submitted do not appear in this table. To see every student's repository status, use the **Repository Status** link shown below the table heading.

## Export controls

**Export grades** and **Download all** are available in the assignment header (top of the page), so they apply to the whole assignment rather than a filtered subset.
