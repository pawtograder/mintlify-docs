# Assignment Dashboard

The assignment dashboard is the default landing page for each assignment. It provides grading controls, score statistics, a rubric breakdown report, and the full submissions table — all in one place.

## Accessing the Dashboard

Navigate to any assignment to view its dashboard. The dashboard is the first tab (**Dashboard**); the second tab (**Grading assigned to me**) shows only the submissions assigned to the current grader.

## Grading status panel

At the top of the dashboard, the grading status panel shows:

- **Graded / Total**: How many submission reviews have been marked complete out of the total.
- **Released / Total**: How many reviews have been released to students.

Three assignment-level actions are available here:

- **Finalize grading** — marks every eligible submission review complete (those whose required rubric checks are all applied). Shows an eligibility preview before confirming. This does not release grades to students.
- **Release all** — makes grades visible to all students for every submission in the assignment.
- **Unrelease all** — hides grades from all students (reverses Release all).

Per-submission release and unrelease remain available in the submissions table by selecting rows and using the **Release** / **Unrelease** buttons.

## Score statistics

The score statistics section shows compact stat tiles for:

- **Total score** — min, average, max, and count across graded submissions.
- **Autograder score** — same breakdown for the automated test score.
- **Submissions per student** — distribution of how many attempts each student has made.

Each tile includes a sparkline histogram. Click **Show detailed distributions** to expand full-size histograms for all three metrics.

Use the **Filter** dropdown to restrict statistics to a specific class section or lab section.

## Rubric breakdown

The **Rubric breakdown** section is collapsed by default. Click to expand it. Once open, it shows how often each rubric check was applied across a cohort of submissions.

### Visualizations

Switch between four views using the buttons in the toolbar:

- **Bars** (default) — a horizontal bar per check showing the application rate.
- **Options** — per-option breakdown for choice-style checks (checks with multiple point values).
- **Table** — a compact table of check name, applied count, and percentage.
- **By section** — a heatmap matrix comparing application rates across class sections.

### Cohort filtering

By default the cohort is all submissions. Use the **Quick filter** dropdown to instantly scope to a criterion or a specific check. For more complex cohorts, click **Advanced filter** to build an AND/OR/NOT filter tree using predicates such as:

- **Check applied** — students who had a specific check applied.
- **Option selected** — students who received a specific option of a choice check.
- **Class section / Lab section** — students in a particular section.
- **Score ≥ / Score ≤** — students whose total score is above or below a threshold.

### Drilling into the submissions table

Click any bar, option row, or table row to filter the submissions table below to the students in that cohort. A banner above the table shows how many students are shown and lets you clear the filter.

You can also click **Filter table to these N** in the toolbar to apply the current cohort filter to the table.

### Rubric items selector

Click **Rubric items** to choose which checks appear in the report. You can include or exclude individual checks, criteria, or entire rubric parts. The selector defaults to all checks.

### Saving a shared default view

Instructors can save the current filter, visualization, and rubric item selection as the shared default for all staff on this assignment. Click **Save as default** (a confirmation popover warns that this is a shared view). All staff see the saved default when they first open the rubric breakdown. Graders can reset to the saved default at any time using **Reset to default**.

### Exporting

Click **Export CSV** to download the current view (cohort + selected checks + visualization) as a CSV file.

## Submissions table

The submissions table lists all students who have made at least one submission. Use it to:

- Select rows and **Release** or **Unrelease** grading for the selected submissions.
- Filter by grader, section, score, or other columns.
- Export grades or download all submissions using the **Export grades** and **Download all** buttons in the assignment header.

Students who have not submitted do not appear in this table. To see every student's repository, visit the **Repository Status** page.
